D: Bare Icons, Monochromatic

Round 1 feedback on A: even with lighter chrome, the boxed 3-way control still "takes too much relevancy" next to the CTA. D removes the container entirely: three bare icon buttons, same 44px touch targets, active state marked by a small underline instead of a sliding background pill — reads as a peer of the nav links, not a boxed "settings widget." Round 3 refinement: the original emoji icons (☀🌙🖥) each render in their own fixed native color regardless of surrounding CSS — the sun emoji in particular always shows yellow. Replaced with simple stroke-based SVGs using currentColor, so every icon inherits the exact same muted/active color as the rest of the cluster — nothing stands out by color, only the active-state underline differs.
