⚠ Found while grounding this sketch: a real background-color question

D-07 (plan 01.8-04, already shipped to production) names the per-game letterbox background as "the site's existing primary brand color (--color-primary / --pk-ramp-600)" — treating those as the same value. They aren't, as of the Sep 10 color-ramp redesign: dark theme's --color-primary is --pk-ramp-600 (#8C2AB7), but light theme's --color-primary is actually --pk-ramp-900 (#45105C). The shipped og-card code comment calls #8C2AB7 "the light theme's primary," which is factually backwards — it's dark's. Nothing visually broke (D-07 named the literal hex directly, so the per-game cards look as decided), but it's a real doc/comment inaccuracy worth a follow-up fix independent of this sketch.

For this asset the plan leaves the ramp step open — "consider whether that same step is right here, or another ramp step reads better at this larger canvas size."
