One button anatomy and four roles, applied to every action in the admin (059–063)

Only the paint changes between systems. Shared rules:
  • Anatomy: 44px tall, 8px radius, 14px/600 label, 16px icon, 8px between buttons.
  • Roles: Principal (one per block, the step the page asks for), Secundaria, Terciaria (dismiss, navigation, disclosure, links ↗), Peligro (never Principal, always confirmed in a sheet).
  • Order: actions are right-aligned with Principal last. A form's button sits beside its field.
  • No disabled buttons: Guardar only appears when there are changes, and forms validate on tap.
  • Sheets keep 059's rows, not buttons.
