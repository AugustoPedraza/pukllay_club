Round 2

C: Overflow, Refined Balance

Round 1 feedback: B's overflow path was the right call, but the trigger and its menu needed better distribution. Two changes: (1) the "⋯" trigger drops its border/background — bare icon, matching the same no-card direction as sketches 013/014's Round 2 toggle, so it reads as a peer control next to the CTA rather than a separate boxed widget; (2) the opened menu is now positioned relative to the header row itself (right: var(--space-4), the same inset the header's own content uses) instead of relative to the trigger button, so it stays flush with the header's true content edge regardless of which control ends up last in the row.

What to look for

  • Click "+2 items" — does the bare "⋯" trigger sit in rhythm with the CTA/toggle now, or still feel bolted on?
  • Open the menu — does its right edge line up with the header's own content edge (same line as "Sumate")?
