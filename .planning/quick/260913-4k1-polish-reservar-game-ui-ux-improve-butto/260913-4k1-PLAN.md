<objective>
Polish the game-detail "Reservar" flow into one industry-standard, mobile-first reservation sheet:
collapse today's two-step modal (name form, then a separate preview + send screen that reads as a
second nested modal) into a single dialog layer where the member types their name and taps one
primary "Reservar por WhatsApp" CTA that is a real wa.me link. Fix button hierarchy (one primary,
ghost Cancelar, 44px close), accessibility (dialog labelling, focus in/return, Enter key), and copy
(Argentine voseo), scoped strictly to the Reservar flow in CatalogLive.Show.

Purpose: the user reported the flow feels like a double nested modal with an unnecessary preview
and weak buttons. WhatsApp itself shows the pre-filled message (editable) before the member sends
it, so an in-app preview step is redundant friction.

Output: updated `show.ex` (dialog markup, one new event handler, hook, triggers, comments),
updated LiveView tests, and a one-paragraph supersession note in the sketch-findings reference.
</objective>
