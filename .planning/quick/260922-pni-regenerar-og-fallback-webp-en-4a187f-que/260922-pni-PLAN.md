<decisions>
**D-1 — The generator is committed and re-runnable, not a throwaway.** `share-card.md`'s own
lesson is "Don't change the ramp's hue without re-baking every static image built from it," and the
reason this task exists is that the 2026-09-12 bake was a one-off nobody could reproduce. A
committed generator turns the next rotation into one command. It lives at
`tools/og-fallback/generate_og_fallback.py` — a new top-level `tools/` directory, because it is
neither app code (`lib/`), nor test code, nor served content (`priv/static/`). It is inert unless
invoked and adds nothing to the Docker image's behaviour.

**D-2 — Encode the WebP losslessly (VP8L), replacing the current lossy VP8.** This is a deliberate
deviation from the original bake, taken to make the verification falsifiable. The two retired
colours differ from the new ones by as little as 1/255 per channel (`#E3D3F0` vs `#DED4F3`);
through lossy compression of antialiased text that difference is indistinguishable from
compression noise, so a lossy asset's tagline colour simply **cannot** be checked. Lossless makes
every baked colour exactly readable and makes re-runs byte-deterministic. Measured cost:
14,330 -> ~47,000 bytes. An OG image at 47 KB is immaterial (platforms cap in the megabytes) and it
is served from a single undigested path with etag revalidation.

**D-3 — Composition is NOT redesigned.** Locked by phase 01.8 D-04/D-05: centered vertical stack,
`isologo-dark.png` at 190px wide, "Pukllay Club" in Bebas Neue 68px uppercase / letter-spacing
0.08em / white, tagline "Tu club de juegos de mesa modernos — Jujuy" in Inter 27px, 20px gaps.
`export.html` is the pixel source, **not** `index.html` (whose preview frame uses a 28px gap).
Only two hex values change.

**D-4 — Both hexes change, not just the background the user named.** The tagline carries the
identical staleness from the identical cause (sketch 058's rotation moved light's
`--color-base-300` too), and `share-card.md` flags it explicitly in the same paragraph. Fixing one
and leaving the other would require a second re-bake for the same root cause.

**D-5 — No new package dependency.** Pillow 10.2.0 is already present and already loads the repo's
woff2 fonts. The plan performs **no** `pip install`, `npm install` or `mix deps` change. If Pillow
turns out to be absent on the executing machine, stop and report — do not install packages.
</decisions>
