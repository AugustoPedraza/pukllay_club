## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser DOM -> CSS custom property on documentElement | The new hook writes a layout-affecting value read by a `body` padding rule; the value originates from the app's own element geometry, never from user input, URL params or server data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-QUICK-01 | Tampering | `.AboutCtaBarMeasure` -> `--pk-about-cta-bar-h` | low | mitigate | Value is `getBoundingClientRect().height` of the hook's own element, numeric, rounded and interpolated into a `px` string — no user-controlled data reaches the property; the hook removes the property in `destroyed()` so it cannot outlive the page. |
| T-QUICK-02 | Denial of Service | ResizeObserver feedback loop | medium | mitigate | Publish only when the rounded height is greater than 0 AND differs from the last published value, so a `body` padding change (the property's only consumer) can never re-trigger an unconditional write; the observed element's height is padding+button+border and is not affected by the property it publishes. |
| T-QUICK-03 | Denial of Service | `visibility`/`transform` hidden state hiding a focusable link | low | mitigate | Hidden state uses `visibility: hidden` (removes the anchor from tab order and the a11y tree), matching this file's existing header-hide mechanism (WR-02) rather than opacity alone. |
| T-QUICK-04 | Information Disclosure | Sticky bar covering footer content | high | mitigate | Live-measured document-end clearance (Task 2) plus a CDP oracle asserting `.pk-bgg-note` is never covered in either theme at the real page bottom (Task 3) — the exact failure that got sketch 052 winner B rejected. |

No package-manager installs in this plan (no npm/pip/cargo dependency added), so the supply-chain
legitimacy gate does not apply.
