<objective>
Make the catalog home page's shelf headers (the Bebas Neue, all-caps "CREA CONEXIONES",
"EQUIPO GANADOR", ... headings rendered by `CarouselRow.carousel_row/1`) into clearly tappable links
that land on the filtered ludoteca grid for that shelf. Today they are inert `<h2>` + subtitle blocks
with no link, no cue and nothing to tap on mobile or desktop.

Live observation at planning time (the evidence this plan's scope rests on):
- The 8 home shelves come from `Catalog.carousel_row_specs/0` + `row_query/1`
  (`lib/pukllay_club/catalog.ex` ~388-417). 7 of them map exactly onto existing URL filters:
  `destacados_del_club` = `tags` holding all three editorial tags (`Vocabulary.editorial_tags/0`, OR
  within a facet, same as `tags_query/1`); `crea_conexiones` / `equipo_ganador` /
  `duelos_memorables` = `tags` with one tag; `descubre_el_hobby` / `ingenio_estratega` /
  `nivel_experto` = `weight_bands` with one band. Both sort by name, which matches the grid's default
  `name_asc` sort.
- `recientemente_anadidos` is `is_expansion == false` ordered by `inserted_at desc`. No URL facet or
  sort option expresses that, and `sort` alone does not flip `filters_active?/1`, so the page would
  stay on the carousels. **Left out on purpose:** that header stays a plain heading. No new facet is
  added (it would need a new sort, a new expansion flag, and a surface-switch change, which is more
  than a quick task should take on).
- `tags` and `weight_bands` are already whitelisted by `CatalogFilters.from_params/1` and already make
  `filters_active?/1` true, so the landing shows the "Resultados" grid plus removable
  active-filter chips ("Etiqueta: #CreaConexiones", etc.). No parsing change is needed.
- The detail page (`CatalogLive.Show` ~811) reuses `carousel_row/1` for "Juegos similares". It has
  no filter destination, so it must stay unlinked. The new attr defaults to `nil`.
- The trailing "Ver todo" tile (`pk-see-all`) was deliberately removed in quick task 260824-u5d, and
  tests refute it. This plan does NOT bring back a tile. The affordance lives in the row header.

Purpose: core value. A new player sees "CREA CONEXIONES — Reglas simples, familiar / diversión
garantizada", taps it, and gets every matching game without knowing the vocabulary.
Output: tappable shelf headers on 7 shelves, the matching CSS affordance, and LiveView tests.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser URL → CatalogLive.Index handle_params/3 | The landing's query string (`tags`, `weight_bands`) is attacker-controllable. Anyone can hand-craft or edit a shelf link. |
| server-built href → rendered anchor | Link targets are emitted into HTML that members click. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-260913-01 | Tampering | `?tags=` / `?weight_bands=` on the landing | low | mitigate | No new param key or parser. Values pass through CatalogFilters.from_params/1 → parse_list_param/2 (capped at 20 elements, closed Vocabulary membership, unknown values dropped) before any query. The Catalog filters bind values as parameters (`type(^tags, {:array, :string})`), with no string interpolation into SQL. Task 2's decode assertion pins each href to only these two keys. |
| T-260913-02 | Tampering / XSS | row_href/1 and the carousel_row header | low | mitigate | Hrefs come only from server-side atom shelf keys and Vocabulary constants through `~p` (percent-encodes interpolated values), never from params or DB text. Title and subtitle render through HEEx auto-escaping, and raw/1 is not used. Task 1/2 tests assert the encoded form (`%23`, a `/?` prefix). |
| T-260913-03 | Spoofing (open redirect) | `<.link navigate>` targets | low | mitigate | Every target is a locally-rooted verified route starting with "/?". No external or user-supplied destination can be produced (asserted in Task 2). |
| T-260913-04 | Denial of Service | filtered landing query | low | accept | The landing runs the existing paginated filter_games/1 with at most 3 tags or 1 band, the same cost as the detail page's existing tag and band links. No new query shape. |
| T-260913-05 | Information Disclosure | shelf links | low | accept | Links expose only public catalog facets that are already reachable from the detail page. No auth or PII involved. |

No package installs in this plan, so no supply-chain (T-SC) row applies.
