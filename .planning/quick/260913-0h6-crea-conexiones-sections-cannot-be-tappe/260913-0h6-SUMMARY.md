# Quick Task 260913-0h6: Crea Conexiones Shelf Headers Become Tappable Filter Links Summary

**7 of the catalog home page's 8 shelf headers (Bebas Neue "CREA CONEXIONES", "EQUIPO GANADOR", etc.) are now real `<.link navigate>` anchors with a persistent bordered "Ver todos ›" cue, landing on the same filtered ludoteca grid the shelf itself shows — no new URL params, no new parsing path.**

## Performance

- **Completed:** 2026-09-13

- **Files modified:** 5

## Accomplishments

- `CarouselRow.carousel_row/1` gained an optional `href` attr: when set, the header title/subtitle wraps in a real navigable anchor (`.pk-row-link`) with a trailing "Ver todos" chevron cue; `nil` (the default) renders every existing caller byte-identically.
- `CatalogLive.Index`'s `row_href/1` maps all 7 filter-expressible shelf keys (`destacados_del_club`, `crea_conexiones`, `equipo_ganador`, `duelos_memorables`, `descubre_el_hobby`, `ingenio_estratega`, `nivel_experto`) to a locally-rooted `/?tags=...` or `/?weight_bands=...` path, re-validated end-to-end through `CatalogFilters.from_params/1`'s existing closed-Vocabulary whitelist.
- `Recientemente añadidos` (`CatalogLive.Index`) and `Juegos similares` (`CatalogLive.Show`) deliberately stay plain, non-interactive headings — neither has a URL-expressible filter destination.
- New `.pk-row-link`/`.pk-row-cue`/`.pk-row-cue-icon` CSS: 44px hit area, `focus-visible` ring, pointer-fine-only hover (tint + chevron nudge + title underline), tap-press feedback, and a `≤480px` density step joining the catalogue's existing 12px/600 type tier — named without "chip"/"pill" so the bespoke-chip drift gate doesn't have to reason about a navigation control.
- Test coverage: an initial tracer test (Crea conexiones anchor shape, a11y wiring, follow-the-link parity, and the no-href contract) plus a table-driven shelf-vs-grid parity test across all 7 linked shelves, an href-shape assertion, and an unlinked-shelf confirmation for `Recientemente añadidos`.
- `.claude/skills/ui-design-system/SKILL.md`'s component/class/type inventories updated: `carousel_row/1`'s attr list now lists `href`, the class inventory lists `.pk-row-link`/`.pk-row-cue`(+`-icon`), and the catalogue type inventory records `.pk-see-all`'s retirement in favor of `.pk-row-cue`.

## Decisions Made

- `href` defaults to `nil` so every pre-existing caller renders byte-identically — no regression risk for `Juegos similares` or `Recientemente añadidos`.
- `destacados_del_club`'s tag list is derived live from `Vocabulary.editorial_tags/0` (same source `Catalog.row_query/1` uses) rather than hardcoded, so the shelf's contents and its own filtered landing can never silently diverge.
- CSS class names avoid "chip"/"pill" substrings on purpose so the pre-existing bespoke-chip drift gate test never has to special-case a navigation control that isn't part of that family.

Not fixed — out of scope per the SCOPE BOUNDARY rule (pre-existing, unrelated to carousel_row.ex/index.ex). Logged to `.planning/WINDOWS.md` below.
