# Quick Task 260913-2x6: Implement id-slug game URLs (/juegos/137-catan) Summary

**Game detail URLs move from `/juegos/137` to `/juegos/137-catan` via a single `Phoenix.Param` impl on `Game` — no schema change, id stays the lookup key, and both HTTP (301) and live-navigation (replace push_patch) self-heal any non-canonical URL back to the current slug.**

## Performance

- **Duration:** ~45 min
- **Completed:** 2026-09-13
- **Tasks:** 3/3
- **Files modified:** 16 (2 created, 14 modified)

## Accomplishments

- `PukllayClub.Catalog.Slug.slugify/1` — stdlib-only (no new dependency) NFD transliteration, apostrophe drop, `[a-z0-9-]` collapse, 60-char cap with trim-after-cut so a cut never leaves a trailing dash
- `Phoenix.Param` impl for `Game` (colocated in `game.ex`) is now the single canonical URL-param source: `"<id>-<slug>"`, or bare `"<id>"` when the slug is empty, raising `ArgumentError` for a nil id. Every `~p"/juegos/#{game}"` call site (`GameCard`, `GamePreview`, `SEO.canonical_url/1`, `SitemapController`, the detail page's share control) picked this up with zero code changes at three of those five sites
- `Catalog.get_game!/1` now accepts both `"<id>"` and `"<id>-<anything>"`, plus a Postgres-bigint range guard (T-2x6-03) so a crafted oversized id 404s instead of risking a 500 in Postgrex
- `PukllayClubWeb.Plugs.GameSEO` resolves the game first (so unknown/junk ids still 404 before any redirect decision), then 301s any non-canonical request to the canonical id-slug path, query string byte-preserved, Location built only from the looked-up game (never `request_path`/host/params — open-redirect and header-injection guards)
- `CatalogLive.Show.handle_params/3` covers the live-navigation half of the same contract (no HTTP request, so the plug never runs) via a `replace: true` push_patch
- Sitemap `<loc>` and the detail page's share URL (WhatsApp/X/copy-link) now carry the id-slug form
- ~190 test call sites across 6 test files mechanically migrated from `~p"/juegos/#{var.id}"` to `~p"/juegos/#{var}"` so no test broke once bare-id requests started redirecting
