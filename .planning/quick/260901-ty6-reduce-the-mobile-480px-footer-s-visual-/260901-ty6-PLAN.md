<objective>
Reduce the ≤480px footer's visual weight along three independent channels — vertical chrome, brand-lockup ink, and link density — without touching a single rendered value above 480px.

Purpose: the mobile footer currently spends ~96px of vertical chrome (48px `.pk-footer` top margin + 24px/24px `.pk-footer-row` inner padding) before any footer content, carries the same 24px Bebas Neue wordmark the desktop lockup uses, and renders its three nav links at the inherited 16px — larger than any body text on the same screen. Mobile is this project's primary surface; the footer reads as the heaviest block on the page.

Output: mobile-scoped retunes of a shared `--pk-footer-*` token scale, contract tests pinning them, live 390px measurements proving them, and updated docs so no existing explanatory comment is left contradicted.
</objective>
