# Quick Task 260913-1s5: Round close icon, inset share button, compact filter pills — Summary

**Sheet close button becomes a true 44x44 circle, the detail-page share button gets 12px corner clearance, and every tappable filter pill drops from a 44px-tall capsule to a compact 28px/32px box backed by an invisible `::after` hit layer that still covers the full 44px touch target.**

## Performance

- **Duration:** ~30 min
- **Tasks:** 3
- **Files modified:** 12

## Accomplishments

- `GamePreview`'s mobile sheet close button (`.pk-sheet-close`) is now an equal-axis `btn-circle min-h-11 min-w-11` (dropped `btn-sm`, which pinned `--size` to 32px on both axes under `btn-circle` while `min-h-11` stretched only the height — the 32x44 oval this task fixed), with its icon carrying `size-5` to match the filter-modal and lightbox close buttons exactly.
- `CatalogLive.Show`'s share-button wrapper moved from an 8px inset (`top-2 right-2`) to a 12px inset (`top-3 right-3`), matching `.pk-sheet-close`'s own 12px, clearing the poster's rounded corner.
- `.pk-pill-interactive`'s drawn `min-height` dropped from 44px to 28px (dense) / 32px (`.pk-pill-comfortable.pk-pill-interactive`, filter-modal + active-filter chips), gained `position: relative`, and a new `.pk-pill-interactive::after` layer (`top`/`bottom: min(0px, calc(50% - 22px))`, vertical-only) restores the full 44px hit area invisibly.
- Row gaps sized to the hit layer's overhang so a wrapped row can never steal taps from the row above: `.pk-poster-panel > .pk-facts-row` `row-gap` 4px → 8px; `GameChips.editorial_tags/1`'s wrapper `gap-1` → `gap-x-1 gap-y-2`.
- `filter_modal.ex`'s `chip_class/1` (both clauses) and `index.ex`'s `.pk-active-filter-chip` no longer carry a per-call-site `min-h-11`, which would otherwise re-inflate the drawn box back to 44px over the new 32px comfortable floor.
- `ux-responsive` and `ui-design-system` skill docs corrected so a future agent reaches for the hit-layer pattern instead of re-adding `min-h-11` to a pill.

## Decisions Made

- The 44px touch-target *contract* (WCAG 2.5.5 AAA target size) stays exactly where it was — on `.pk-pill-interactive` — only its *implementation* moved from a drawn box to an invisible `::after` layer, so no call site needed a new variant name or a migration to a different class.
- Row-gap values were derived arithmetically from the hit layer's overhang `(44 - visible height) / 2` (8px for 28px pills, 6px for 32px pills) rather than picked visually, so the fix is provably correct against the tap-hijack failure mode rather than "looks fine."
- Left every tone (colours, borders, hover/selected states) completely untouched — per `pills-chips.md`, those are UAT-validated and out of this task's scope.
