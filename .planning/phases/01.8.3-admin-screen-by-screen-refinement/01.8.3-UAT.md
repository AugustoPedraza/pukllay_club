- gap_id: G-01.8.3-2a
  truth: "The pinned section caption's `::before` band is drawn around the ink, centred on it — never tint sitting above the text (D-15, 071 d29-31; the regression signal test 4's own note names)."
  status: resolved
  reason: |
    User-requested walk, 2026-09-25: for any section with `--pt: 26px` the band's 44px
    sits entirely above the caption ink. Measured pinned, at 390x844:
      Borradores      (--pt 14px): gapAbove 14px / gapBelow 13px -> asymmetry  1px (correct)
      Juegos del club (--pt 26px): gapAbove 26px / gapBelow  1px -> asymmetry 25px (defect)
    Both bands are 44px and both are `rgb(241, 236, 253)`.
  severity: major
  test: 2
  root_cause: |
    `assets/css/admin/juegos.css:303` — the pinned rule sets `::before { top: 0 }`,
    anchoring the band to the header's BORDER-BOX top, but nothing in the pinned state
    reduces the header's own `padding-top: var(--pt)` (`juegos.css:216`). The ink
    therefore stays `--pt` below the band's top edge, and `gapAbove` equals `--pt`
    exactly (14px and 26px measured, against `--pt` of 14px and 26px).

    The rule's own comment claims it "moves the INK's effective position relative to a
    band fixed at the 44px target" — but no such rule exists; only the band moves. The
    44px HEIGHT invariant still holds, because `bottom` is re-derived as
    `--pt - 2 * --bandp`, which is precisely why this is invisible to every existing
    guard: `admin_shell.mjs` asserts band height, band background and the resting
    ink-to-ink air ratio, and all three still pass.

    It looks correct on the first section only by coincidence: `--pt: 14px` there is
    within ~1px of `--bandp` (12.9px), so that one band happens to land centred.
  artifacts:
    - path: "assets/css/admin/juegos.css"
      line: 303
      issue: "Pinned `::before` sets `top: 0`, decoupling the band from the ink, which stays at `padding-top: var(--pt)`."
    - path: "assets/css/admin/juegos.css"
      line: 216
      issue: "`.pk-admin-juegos-section-header` keeps `padding: var(--pt) 16px 0` in the pinned state; nothing overrides `--pt` when pinned."
    - path: "test/visual/admin_shell.mjs"
      issue: "`measureJuegosSectionPinned` reads bandTop/bandBottom and the caption ink, but never compares them — so a band fully decoupled from its ink passes every check."
  missing:
    - "Make the pinned band's top track the ink (e.g. `top: calc(var(--pt) - var(--bandp))`) and re-derive `bottom` so the 44px height invariant still holds for every `--pt`."
    - "Add an ink-position assertion to `admin_shell.mjs`'s Juegos check — gapAbove vs gapBelow within a small tolerance — so a height-only guard can never again pass a decoupled band."
