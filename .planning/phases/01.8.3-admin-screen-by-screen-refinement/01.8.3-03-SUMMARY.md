# Phase 01.8.3 Plan 03: Pinned Caption Fix + Juegos Row/Caption Anatomy Summary

**Section captions on `/admin/juegos` now pin the instant they visually pin (a redundant real-viewport-rect AND-clause deleted, not a missing rootMargin added), fill with a `::before` band derived from a declarative `calc()` instead of a copied sketch constant, and Juegos rows/captions ship at 64px/14-600-uppercase through Juegos-scoped CSS overrides that leave the 8-screen-shared `.pk-admin-row`/`.pk-admin-list-section-label` atoms untouched.**

- **Completed:** 2026-09-24

## Accomplishments

- `admin_list.js`'s pin predicate is now `!entry.isIntersecting` alone — RESEARCH.md's refutation of CONTEXT.md's own diagnosis held: the `rootMargin` already existed and was correctly sized, but a redundant, stricter `entry.boundingClientRect.top < 0` AND-clause dominated it and re-opened the ~45px window. Deleting that clause (not adding a rootMargin) is the fix.
- The observer's `rootMargin` is now measured once in `mounted()` from `#juegos-search-wrap`'s real rendered height (`this.pinnedBandPx`), with a traceable `60` (`4 + 48 + 8`) fallback rather than a silent `0` — `PAGE_BAR_BAND` (the deleted page bar's `44` literal, kept alive by plan 01 specifically because this plan owns its removal) is gone entirely.
- `juegos.css` gained the `::before` pinned-caption band (071's d29-31 mechanism, ported): a resting rule that moves the band around the ink's resting position and a pinned rule that moves the ink's effective position relative to a band fixed at a declared 44px target, plus hover/active variants that paint the same band (never the box). `--bandp` is `calc((44px - var(--cap-box)) / 2)`, never the sketch's own `12.9px` fixture constant.
- The section captions' sticky offset is now `top: var(--pk-juegos-pinned-h)` (`60px`, declared once on `.pk-admin-juegos`) instead of a literal `44px` left over from the deleted page bar — the same number the JS hook's fallback documents, so the stylesheet and the hook are traceably in agreement even though neither reads the other's value directly.
- Juegos rows/captions gained their D-13 anatomy (64px rows, 40px covers, 15/400 wrapping names, 14/600 uppercase tracked captions) entirely through `.pk-admin-juegos-rows > .pk-admin-row` / `.pk-admin-juegos-section-header .pk-admin-list-section-label` overrides — `components.css`'s shared `.pk-admin-row`/`.pk-admin-list-section-label` rules (consumed by 8 other admin screens) are provably untouched by this plan's commits.
- `mix quality` green: 1866 tests, 0 failures, hex.audit/deps.audit/format/credo/sobelow all clean.
