**1. [Rule 1 - Bug] `width: auto` alone did not restore full-bleed after the negative-margin compensation**

- **Found during:** Task 3's own sweep probe run (editor-weight-band-sheet)

- **Fix:** The walker now excludes any element matching the full-bleed selector from the "control" (border-box) fallback branch entirely, letting the walker continue into its subtree where the nested label's own direct text is picked up correctly as ink.
- **Files modified:** test/visual/admin_shell.mjs

- **Files modified:** test/visual/admin_shell.mjs (this function's own local copy, per this file's established one-copy-per-function convention — not a shared helper)
- **Verification:** Re-ran the probe; editor-weight-band-sheet's Test 5 ink measurement now succeeds.
