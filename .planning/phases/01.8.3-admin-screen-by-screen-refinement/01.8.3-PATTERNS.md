### `assets/js/hooks/admin_list.js` — pinned search hide/return (hook, event-driven)

**Analog:** `assets/js/hooks/admin_rail.js` (full file, 82 lines) — port this logic verbatim,
Juegos-scoped ids, into `admin_list.js`. Per D-18's per-screen-owns-its-hook convention this is a
**copy**, not a shared import.

```js
// assets/js/hooks/admin_rail.js:23-66 — the block to port
export default {
  mounted() {
    this.searchWrap = this.el.querySelector("#estantes-search-wrap")
    this.searchInput = this.el.querySelector("#estantes-search-input")
    this.lastScrollY = window.scrollY
    ...
    this.onScroll = () => {
      if (!this.searchWrap) return
      const y = window.scrollY
      const goingDown = y > this.lastScrollY
      this.lastScrollY = y
      const focused = document.activeElement === this.searchInput
      const nearTop = y <= 140
      if (focused || nearTop) {
        this.searchWrap.removeAttribute("data-pinned-hidden")
      } else if (goingDown) {
        this.searchWrap.setAttribute("data-pinned-hidden", "true")
      } else {
        this.searchWrap.removeAttribute("data-pinned-hidden")
      }
    }
    window.addEventListener("scroll", this.onScroll, {passive: true})
  },
  destroyed() {
    window.removeEventListener("scroll", this.onScroll)
  },
}
```

**What survives unchanged in `admin_list.js`:** only the pin-observer half (lines 90-119 in the
current file — the `IntersectionObserver` toggling `data-pinned` on section headings), and it
needs a **different rootMargin/threshold fix**, not a copy from `admin_rail.js` (which has no
section-pin logic at all). Per RESEARCH.md's root-cause analysis: drop the redundant
`entry.boundingClientRect.top < 0` AND-clause (or align the threshold to the rootMargin's offset)
— `rootMargin` is already correctly computed, the bug is the second clause overriding it.

**What must be deleted entirely from `admin_list.js`** (dead once D-06/D-09 land): `this.title`,
`this.pageBar`, `this.pageBarBack`, `this.backRow`, and the whole page-bar-visibility half of
`onScroll` (current lines 47-59, 63) — `.pk-admin-page-title` and `.pk-admin-back-row` will no
longer exist in this page's DOM at all.

**PAGE_BAR_BAND constant** (`admin_list.js:32`, `const PAGE_BAR_BAND = 44`): repurpose to the new
pinned row's real height (48px per D-07), do not leave it named after the deleted page bar.

### Completion toast (D-11) — controller, event-driven (PubSub → snackbar)

**Analog:** `lib/pukllay_club_web/live/admin/estante_live/index.ex:894-900`
```heex
<AdminComponents.snackbar
  :if={@action_snackbar}
  id={@action_snackbar.id}
  message={@action_snackbar.message}
  action={@action_snackbar.action}
  on_close={JS.push("dismiss-action-snackbar")}
```

`action` is a `%{label:, event:}` map — passing it sets the 10s-with-action variant (omitting it
gives 4s, per `admin_components.ex:969-1009`). For Juegos' completion toast: assign
`@enrichment_toast` (or similar) from `handle_info({:game_enriched, game_id}, socket)`, set

```elixir

end
```
Per RESEARCH.md, this must branch on `Catalog.get_game!(game_id).enrichment_status` (`"enriched"`
vs `"failed"`) to build the D-17 toast copy — `game.name` alone is sufficient for both variants (no
extra lookup): the real title on success (already overwritten by `Enrichment.build_attrs/4` before
`enrichment_status` flips), the `"Juego #<bgg_id>"` placeholder on failure (never overwritten,

## Shared Patterns

### Sheet shell
**Source:** `AdminComponents.sheet/1` (`admin_components.ex:824-875`) — `attr :id, :title,
:subtitle, :cover, :open, :on_close, :class`, `slot :commit`, `slot :inner_block`, no Cancelar row.
**Apply to:** the `+` sheet and the edition-prompt-inside-sheet transform (D-10, D-12).

### Snackbar (toast)
**Source:** `AdminComponents.snackbar/1` (`admin_components.ex:969-1009`) — `action` map present
= 10s-with-action; absent = 4s.
**Apply to:** the completion toast (D-11).

### A1/A3 action anatomy
**Source:** `AdminComponents.action/1` (`admin_components.ex:90-168`) — `disabled` only valid with
`commit={true}` (raises otherwise); mirror `save_bar/1`'s `commit disabled={!@dirty}` pattern
(`admin_components.ex:1047-1056`).
**Apply to:** the `+` icon action (A3) and the sheet's `Agregar` button (A1, disabled-while-empty
per D-10).

### Never `phx-value-value`
**Source:** project-wide convention (`[[feedback_no_phx_value_value]]`), already followed
throughout `index.ex` (`phx-value-game-id`, `phx-value-section-key`).
**Apply to:** any new markup in the `+` sheet or pinned row — do not introduce `phx-value-value`.

### Shared-class scoping discipline (the two traps)
**Source:** `juegos.css:196-214`'s own row-divider selector shape (`.pk-admin-juegos-rows > .pk-admin-row + .pk-admin-row`).
**Apply to:** every D-13 row/caption override — always scope through a Juegos-specific ancestor
class, never edit `components.css`'s shared `.pk-admin-row`/`.pk-admin-list-section-label` rules
directly (8 other admin screens consume them).
