## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Prevented a `PAGE_BAR_BAND` `ReferenceError` the plan's literal instruction would have introduced**
- **Found during:** Task 1 (admin_list.js rewrite)
- **Issue:** The plan's action text says "Delete `PAGE_BAR_BAND` (line 32)", but `setupPinObserver` — the pin-observer half the same paragraph requires to stay byte-identical in this task — reads that constant in its `rootMargin` computation. Deleting the declaration while the reference survives would throw a `ReferenceError` the instant the hook mounts (`mounted()` calls `setupPinObserver()` unconditionally), breaking the section-caption pinning on every page load. No ExUnit test would have caught this (no JS execution in `LiveViewTest`), so it would have shipped silently broken.
- **Fix:** Kept the `const PAGE_BAR_BAND = 44` declaration, documented inline why it survives and that plan 03 owns repurposing/renaming it alongside its own observer fix (D-15).
- **Files modified:** assets/js/hooks/admin_list.js
- **Verification:** `mix assets.build` succeeds (esbuild resolves the reference); manual reasoning traced through `mounted()` → `setupPinObserver()` → `rootMargin` interpolation.
- **Committed in:** 537efffb (Task 1 commit)
