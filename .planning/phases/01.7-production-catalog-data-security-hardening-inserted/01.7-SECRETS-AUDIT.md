## Invocation

Full-history sweep, walking all refs rather than only what's reachable from the current tip
(this repo is effectively single-branch, which likely makes the difference moot in practice —
but AUDIT-01 asks for a full-history sweep, and "likely moot" is a claim this record states
rather than assumes):

```bash
gitleaks detect --source . \
  --log-opts="--all --full-history" \
  --report-path "$SCRATCHPAD/gitleaks-report.json" \
  --exit-code 0
```

The raw JSON report was written only to the session scratchpad directory (never into this
repository's working tree). Output: `1142 commits scanned`, `leaks found: 1`.
