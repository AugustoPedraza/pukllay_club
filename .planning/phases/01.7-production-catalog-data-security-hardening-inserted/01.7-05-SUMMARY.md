## Accomplishments

- `config/dev.exs`'s `PukllayClub.Repo` block now resolves from `DATABASE_URL` when set,
  falling back to today's exact hardcoded local values when unset — verified byte-equivalent on
  the unset path and confirmed the override both applies and forces
  `show_sensitive_data_on_connection_error` off, via two `mix run --no-start` assertions

  idempotency behaviours against `Catalog.upsert_game!/1`'s `csv_row` conflict target — a repeat
  upsert leaves one row, returns the same primary key, content fields (including array-typed
  `mechanics` and `description`) match, `inserted_at` is preserved while `updated_at` may move,
  and two distinct `csv_row` values still produce two distinct rows

  usage-rules block (verified byte-identical after the edit) — documenting the completed one-time
  restore (pointing at `01.7-SEED-RESTORE.md` for the real commands) and the future re-seed path

  mandatory `mix catalog.translate_descriptions --only-english` follow-up after any full re-seed)

  `--only-english` is the resumable, quota-conserving invocation already built for exactly this
  scenario (re-translating rows a re-seed reverted to English).
