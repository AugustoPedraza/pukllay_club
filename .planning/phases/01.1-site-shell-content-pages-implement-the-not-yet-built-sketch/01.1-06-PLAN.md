<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → the filter surface's events | Facet toggles and scalar inputs carry attacker-controlled `phx-value-*` payloads into `CatalogLive.Index`'s assigns. |
| URL query string → `handle_params/3` | A brand-new untrusted input surface: arbitrary params reach filter assigns and then the composed Ecto query. |
| render → detail-page chip hrefs | Vocabulary labels and tag strings are interpolated into catalog URLs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01.1-01 | Tampering | the filter surface's `toggle-facet` / `set-scalar` events | high | mitigate | The surface is markup only — it dispatches the already-shipped, already-tested handlers unchanged, so no new echo path is created. `facet_assign_key/1`'s literal string clauses with a catch-all still reject any unrecognised facet name, and `parse_int/1` still nils a non-integer.
