## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Phoenix router | `/club` and `/quienes-somos` are public, take no params and hold no session state; nothing user-supplied reaches the render. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
