## Phase Goal (MVP user story)

**As a** solo developer/operator, **I want to** stand up a trivial-but-real Phoenix app with a health endpoint, pinned toolchain, and crash reporting, **so that** there is a genuine, bootable release to push through the deploy pipeline the rest of this phase builds.

<objective>
Scaffold the Phoenix application from scratch (the repo currently has zero application code) and produce a bootable OTP release with a hand-added `/up` health route, a pinned local toolchain, the `mix quality` gate alias, and Sentry crash capture. This is the app-layer vertical slice every later plan deploys, gates, and backs up.

Purpose: DEPLOY-01's app half — a placeholder page plus a working `/up` endpoint — plus the release artifacts (Dockerfile, `bin/migrate`, `release.ex`) that plan 00-04's Kamal/entrypoint work customizes.
Output: A Phoenix app that boots locally, serves the stock welcome page at `/`, returns 200 at `/up`, passes `mix quality`, and reports crashes to Sentry.
</objective>
