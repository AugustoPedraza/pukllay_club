<objective>
Bake a "PUKLLAY CLUB" companion wordmark into the About hero's scroll-morph isologo, and sync the
hero's eyebrow line to the same dock-crossing boolean that already drives the header reveal.

Purpose: sketch 050 found that a first-time visitor scrolling the About page saw a large graphic
mark with no readable name until it docked into the header. This plan gives the mark its own name,
riding the mark's existing per-frame transform for free, and makes the hero's eyebrow yield to the
header at the same instant rather than lingering behind a revealed header. It also satisfies the
folded "Surface Pukllay Club brand name in site content" todo (D-15), About-page-scoped.

Output: new `.pk-about-morph-name` markup + CSS, a new `.pk-about-hero-eyebrow` class + its
docked-state rule, two new `classList.toggle` call sites inside the existing `.AboutHeaderMorph`
colocated hook, and new assertions in `about_header_morph_test.exs`.
</objective>
