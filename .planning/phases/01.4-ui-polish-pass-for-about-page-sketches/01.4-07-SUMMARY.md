# Phase 01.4 Plan 07: Contacto Map Thumbnail Coverage Gap Closure (G-01.4-2) Summary

**Closed G-01.4-2 (the Maps thumbnail caption ghosting through the map and swallowing up to 74.9% of the box in the 640-767px band) by porting sketch 048's short mobile caption, making the caption chip fully opaque and single-line, and flooring the thumbnail's height for the two-column band — three independently-necessary fixes proven by a prior debug session's differential experiment.**

## Performance

- **Duration:** ~25 min
- **Tasks:** 2 (both executed this session)
- **Files modified:** 3 (plus 1 new deferred-items.md log)

## Accomplishments

- Ported sketch 048's short mobile caption ("Cómo llegar ↗", copied verbatim including its arrow glyph) as a second `.pk-about-map-label` variant alongside the existing 59-character desktop string, gated at the `lg` (1024px) breakpoint using the same `hidden`/`lg:block` utility-pair precedent already established by this file's hero tagline.
- Rewrote `.pk-about-map-label` from an 88%-opaque `color-mix(...)` fill (validated in the source sketch against a flat gradient placeholder that had no real image behind it) to a fully opaque `var(--color-base-100)` chip, inset `0.5rem` from all three edges (not full-bleed), with a `--color-base-300` border and `--radius-box` radius matching the card's own contact links, plus `white-space: nowrap` / `overflow: hidden` / `text-overflow: ellipsis` as a structural single-line ceiling.
- Added `min-height: 7rem` to `.pk-about-map-thumb` alongside its existing `aspect-ratio: 21/9`, flooring the box at the 640-767px two-column band where the parent's `sm:grid-cols-2` was previously letting it collapse to a measured 93px tall.
- Left `object-fit`, `overflow`, `border-radius` and the `<img>`'s own sizing completely untouched — the debug session had already eliminated all of them by measurement (0px image-to-box gap at nine viewport widths, both themes).
- Extended `about_live_test.exs`'s existing "Contacto card map thumbnail" describe block with structural (both caption variants render, correct utility classes) and CSS-fact (opaque single-source background, `white-space: nowrap`, no `display` property, `min-height` present) coverage, plus a new describe block documenting the test suite's own oracle boundary and guarding the caption-length invariant that made the original bug possible.
