<objective>
Fix the two detail-page gaps the human UAT caught after automated verification scored 34/34 — one a
real cascade bug that grep-on-markup structurally cannot see, one a visual-weight problem whose
intended fix shipped as a measured no-op.

**G-01.2-5 — the mobile position bug.** Every custom `.pk-*` rule in `app.css` is written outside any
`@layer` block, while Tailwind v4's utilities live inside `@layer utilities`. Per the CSS Cascading
and Layers spec, unlayered rules always beat layered ones regardless of specificity or source order.
So `.pk-poster-col { position: static }` (app.css:2279-2281, unlayered) silently defeats the
`relative` utility plan 01.2-04 added to `show.ex:292` for exactly this purpose. Below 768px the
poster column computes to `static`, no ancestor between it and the document root is positioned, and
the absolutely-positioned share-control wrapper resolves against the initial containing block — it
renders near the top-right of the *whole page*. At ≥768px the same file separately gives the column
`position: sticky`, which is non-static and accidentally satisfies the requirement, which is exactly
why the symptom was "and mobile is even worse". The existing regression test string-matches the class
attribute and is green with the defect present.

**G-01.2-5's second half and G-01.2-6 — visual weight.** The panel's only boundary is a
`base-200`/`base-100` fill pair measured elsewhere in this codebase at 1.415:1 (light) / 1.086:1
(dark), roughly half this app's own documented 3:1 non-text floor. And plan 01.2-04's `btn-sm`
addition to `share_control/1` was a complete no-op: `min-h-11`/`min-w-11` were already on the same
class list and clamp any smaller size upward, so the button measured 44×44px before and after. The
bar's real ratio at 390px is ~306px against 44px — about 7:1.

Sketches 027 and 028 resolved both visual questions with a human in the loop. This plan ports their
winners literally.

Purpose: the detail page is the surface a member decides on, and right now its decision panel does
not read as one.
Output: a poster column with a containing block at every width, sketch 027's Elevated Shadow panel,
sketch 028's Stacked bar, and a written cascade-hazard note so this class of bug is findable next
time.
</objective>
