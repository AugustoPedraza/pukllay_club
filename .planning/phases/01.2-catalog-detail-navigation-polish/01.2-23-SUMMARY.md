# Phase 01.2 Plan 23: Mobile Masthead Dot Compaction and Buy-Box Grouping Summary

**Narrowed the gallery-dot hit box to 24x44 CSS px (24px WCAG width floor, 44px height floor kept) and moved the facts pills inside `.pk-poster-panel` as its first child, closing all three UAT-test-8 complaints (spread-out dots, floating pills/photo/CTA, mismatched left/right margins) with two small, targeted CSS/markup changes.**

## Performance

- **Duration:** ~15 min
- **Tasks:** 2
- **Files modified:** 3

## Accomplishments

- Gallery dot row: visible mark-to-mark distance dropped from ~40px to 16px by narrowing `.pk-gallery-dot`'s hit box from a 44px square to 24x44 (width shrinks to the WCAG 2.5.8 AA floor, height keeps this layer's own 44px `min-h-11` floor) and zeroing `.pk-gallery-dots`' gap — full arithmetic and the 24-vs-44 tradeoff recorded directly in the CSS rule.
- Facts pills relocated to be `.pk-poster-panel`'s first child (was `.pk-poster-col`'s first child, directly above the panel) — the pills now inherit the panel's 1rem card padding, so their left/right edges coincide with the poster photo's edges and the whole cluster (pills + photo + dots) reads as one bordered/shadowed card instead of two floating pieces.
- The one CSS rule scoped to the facts row's old parent (`.pk-poster-col > .pk-facts-row`) was re-pointed to `.pk-poster-panel > .pk-facts-row` with its three declarations kept byte-identical — only the selector and its provenance comment changed.
- Every existing test assertion that queried the old parent selector was re-pointed to the new one; the adjacency assertion was rewritten to check the row is the panel's first child followed by the poster frame, and a new negative assertion pins that the old selector now matches nothing.
- New source-level test (`.pk-gallery-dot`'s declared width/height) added so a future edit that drops either the 24px width floor or the 44px height floor fails loudly.

## Decisions Made

- Gallery dot hit box narrowed asymmetrically (24px width / 44px height) rather than both dimensions, since a 44px-wide box is geometrically incompatible with reading as a compact three-dot indicator, and 24px is the WCAG 2.5.8 AA target-size minimum rather than an arbitrary shrink.
- Rejected a negative horizontal margin as the mechanism for closing the remaining visual gap between dots (it would let hit boxes overlap and silently steal taps from a neighboring dot) — narrowing the box itself and zeroing the gap was used instead.
- Facts row moved into the existing `.pk-poster-panel` rather than introducing a new shared wrapper around pills + photo + dots — per sketch 037's finding (recorded in the sketch-findings skill), proximity/alignment inside an existing card was the smaller diff and avoided adding a second visual "grouping" mechanism to the design system.
