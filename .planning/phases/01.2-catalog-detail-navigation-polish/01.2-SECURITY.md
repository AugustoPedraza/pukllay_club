## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Public catalog/detail HTTP surface | Unauthenticated member browsing, search, filter, breadcrumb navigation | Query params (`from`, `q`, facet/scalar filters), no PII |
| LiveView event channel | `phx-click`/`phx-change`/`phx-value-*` events from client to server (search, filters, load-more, lightbox, dot/thumbnail nav, share, CTA) | Client-originated event payloads; server treats all as untrusted and re-derives state server-side |
| Ecto/Postgres query layer | Filter, similarity, and recommendation queries built from client-influenced params (bands, mechanics, themes, similarity offsets) | Typed/parameterized Ecto fragments; no raw SQL interpolation |
| Static asset build (CSP) | Colocated LiveView JS hooks compiled into the built stylesheet/script bundle | No inline `on*=` handlers; hooks extracted at `mix assets.build` time |
| Client-rendered chip/label text | Filter chips, active-filter summary, share labels rendered from member-supplied query/facet values | HEEx auto-escaping; fixed vocabulary lookups instead of raw echo where feasible |
