<objective>
D-01 and D-02: make the flat "El catálogo completo" grid exclusively the search/filter
results view, so the default browse surface is the 8 carousel rows alone — and make the
filter modal's existing primary CTA the one path to the full-catalog grid, with no new UI.

Purpose: today the grid renders unconditionally below the carousels, so every unfiltered
visit ends in an undifferentiated 400-card wall that competes with the curated shelves
above it. The Netflix/Steam/Amazon precedent the user cited is that curated rows are the
browse surface and a flat grid only ever answers a query. This plan makes that true here.
Output: one new predicate, one new assign, one changed event binding, and the gating.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> `apply-filters` / `close-filters` / `clear-filters` LiveView events | Any connected client can dispatch these events with arbitrary payloads at any rate. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01.2-09 | Elevation of Privilege | the `browse_all` gate changing what data a visitor can reach | low | accept | No authorization boundary is involved. Both surfaces render the same public, unauthenticated catalog (CATALOG-08) through the same `filter_games/1` predicate with the same `LIMIT`; the gate selects a presentation, never a permission or a row set. |
| T-01.2-10 | Tampering | a crafted `apply-filters` payload | low | mitigate | The handler ignores its params entirely (`_params`) and can only set a boolean to `true`. There is no value to inject and no atom built from client input — consistent with this module's T-01-37 discipline. |
| T-01.2-11 | Denial of Service | event spam on `apply-filters` | low | accept | The handler runs no query and touches no database — it assigns one boolean. LiveView processes events sequentially per socket, so the worst case is a re-render, which is already true of every other control on this page. |
| T-01.2-12 | Information Disclosure | the grid disappearing from the default view hiding content from members | low | accept | Not a security concern but a discoverability one, and it is the explicit intent of D-01/D-02: the full catalog remains reachable in one action via the filter modal's CTA, and every game remains reachable by search and by direct URL. |
| T-01.2-SC | Tampering | package-manager installs | n/a | accept | No npm/hex/pip/cargo dependency is added by this plan. No package-legitimacy gate applies. |
</threat_model>
