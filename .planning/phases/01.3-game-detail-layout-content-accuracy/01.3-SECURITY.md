# Phase 01.3 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| BGG XML API → `BggClient.parse_items/1` | Untrusted third-party XML crosses into the app and is parsed | Board-game metadata (stats, rank, artist/designer names) |
| Developer machine → BGG API | Outbound authenticated requests | `bgg_api_token` |
| Developer machine → Google Gemini API | Outbound authenticated requests | `gemini_api_key`, BGG description text as prompt input |
| Stored BGG description → Gemini prompt | Third-party content crosses into an LLM prompt, at catalog scale | Third-party (public) game descriptions |
| Gemini response → `games.description` → HEEx render | Model-generated text crosses into the database, then into rendered HTML | LLM-translated description text |
| `games` table → `CatalogLive.Show` / `CatalogLive.Index` HEEx render | Stored third-party strings (description, artist/designer names, title) cross into rendered HTML | BGG-sourced catalog text |
| browser URL → `CatalogLive.Index.handle_params/3` | Attacker fully controls `?designers=`/`?artists=` query string content, length, and count | Open-text (non-whitelisted) filter params |
| `?from=` value → `CatalogFilters.catalog_path/1` | Breadcrumb re-decodes a carried query string, now including opaque creator strings | Round-tripped query params |
| visitor tap → LiveView `toggle-description` event | Untrusted client event crossing into server-held view state | Boolean toggle only |
| Detail page → boardgamegeek.com | Four outbound links open in a new browsing context | None (outbound navigation only) |
| Human → gitignored config file | A real API key is handled in cleartext once and written to disk | `bgg_api_token`, `gemini_api_key` |
| Developer machine → `pukllay_club_dev` | Bulk write across the whole catalog (enrichment/translation Mix tasks) | ~385-393 row updates, narrow changeset allowlists |
| hex.pm → build | A new third-party dependency enters the supply chain | `instructor_lite` package (audited, approved) |
