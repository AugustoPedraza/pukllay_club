## Tests

### 1. Recomposed reading-column visual read at 390px and 1440px
expected: |
  Open a fully-enriched game's detail page (e.g. Wingspan Asia, Spirit Island) at both widths.
  The composition should read as title → lightweight accent-coloured hashtags → description →
  one two-column fact grid (Diseñadores/Ilustradores/Mecánicas/Temáticas) → Comunidad BGG, with
  no divider line inside the reading column. The hashtags should read as text, not a filled
  pill. The fact grid should visually pair up into two columns at 1440px and stack to one column
  at 390px. "Comunidad BGG" should read as a sensible group label, not "Avanzado".
result: pass
note: |
  Root cause: not a bug — GameChips.editorial_tags/1 correctly hides the row when
  game.tags == []. 74% of seeded games have no editorial tags (narrow 3-column CSV
  mapping); the user likely viewed plain "Wingspan" (untagged) rather than "Wingspan
  Asia" (tagged). Re-verified against the UAT's own named examples (Wingspan Asia,
  Spirit Island) — hashtag row renders correctly in both themes/widths. Accepted as
  intended per product decision 2026-08-31; no code fix applied.

### 4. Description justify, mid-word-cut risk, and toggle ink alignment
expected: |

  BOTH light and dark theme: (1) the description text is justified at both widths; (2) the
  clipped third line ends on a whole word — if any combination cuts mid-word, the pre-decided CSS
  fallback recorded in 01.3-08-PLAN.md's planner_note should be applied rather than re-tuned or
  re-sketched; (3) the "…" and the chevron read as vertically aligned on their visible ink, not
  merely on their boxes — if not, re-tune `.pk-desc-toggle-icon`'s `translateY` against the real

  reliably across several round trips.
