### 1. Recomposed reading-column visual read at 390px and 1440px
expected: |
  Open a fully-enriched game's detail page (e.g. Wingspan Asia, Spirit Island) at both widths.
  The composition should read as title → lightweight accent-coloured hashtags → description →
  one two-column fact grid (Diseñadores/Ilustradores/Mecánicas/Temáticas) → Comunidad BGG, with
  no divider line inside the reading column. The hashtags should read as text, not a filled
  pill. The fact grid should visually pair up into two columns at 1440px and stack to one column

  Asia" (tagged). Re-verified against the UAT's own named examples (Wingspan Asia,
  Spirit Island) — hashtag row renders correctly in both themes/widths. Accepted as
  intended per product decision 2026-08-31; no code fix applied.
