## Known Limitation Carried Into This Phase

`snackbar/1` renders `data-timeout` but no JS consumer dismisses it (research D6/A4, grep-only,
not browser-verified). The user accepted this for Phase 01.8.4: new snacks ship through the
existing mechanism unchanged, and no dismiss timer is built here. In-scope mitigation: clear any
existing snackbar when setting a new one, so the three new no-action snacks cannot stack.
