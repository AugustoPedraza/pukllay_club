# Phase 01.8.4 Plan 01: A game lands at the chosen slot Summary

**The destacada rail's "+" now places a game at the exact gap tapped: a FOR UPDATE-locked `Sections.insert_game_at/3` with dense renumbering, a range-checked `Admin.Params` guard, the N+1 slot rail and the `¿Qué juego va acá?` sheet, with `Juego agregado` + `Deshacer`, plus the `move_game_to/3` / `rest_index/2` pair the later plans build on.**

## Accomplishments

- `Sections.insert_game_at/3` re-reads the section row `FOR UPDATE`, takes `kind`/`featured` from that row, validates in a fixed order (bounds, already-member, game exists and not retired, cap), splices, and rewrites positions `1..n`. Returns typed error atoms for every rejection and never raises, including for an id above the bigint maximum and an unknown in-range id (both crash modes were reproduced by running them during research).
- `PukllayClubWeb.Admin.Params` is the shared untrusted-param guard: strict `{int, ""}` parse, integer-or-binary input, explicit range. `open-add-sheet` and `add-sheet-pick` use it exclusively; the slot range is `0..length(live_ids)` from a fresh `Sections.section_members/1` read.
- The rail is always rendered with `n + 1` real focusable `<button>` slots, each with a Spanish accessible name (`al principio` / `entre X y Y` / `al final`), inside a `role="group"` labelled by `#web-destacada-name`. Covers are `pk-admin-web-box` buttons with a 12px caption; `AdminRail` is mounted on `#web-destacada` and the placed cover carries `data-pk-rail-selected`.
- The `¿Qué juego va acá?` sheet puts the search field in the `:commit` slot with `data-pk-sheet-autofocus`; `AdminSheet`'s `onOpen` looks that up before the close button (opt-in, so every shipped sheet is unchanged). A stale sheet says `La fila cambió mientras elegías un juego. Probá de nuevo.` and writes nothing.
- `clear_snackbars/1` gates every snack-setting write in the module (including the shipped `Fila guardada.`, `remove-game` and `done-reorder`), so at most one `[data-pk-snackbar]` renders in either order.
- `move_game_to/3` + `rest_index/2` (rest-list coordinates, no cap check, returns `from` for a plain-inverse undo) land for plan 03's ADD-05.
