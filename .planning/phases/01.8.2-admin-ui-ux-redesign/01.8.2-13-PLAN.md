<objective>
D-08's Estantes page: search-first, one job — find a box. Idle prompt and field at the
optical centre; focus shows the last three searches; typing shows suggestions; picking a game
raises the page and opens the whole estante as a rail with that game lifted. Pendientes sits
behind a header badge, never as a list on the page.

Purpose: this expands plan 01.8.2-01's tracer, which proved the rail renders in real position
order. The search, the dropdown and the raise are what turn that into the screen the restart
settled — R8's original bug was "five taps to a wrong answer", and the shipped screen
rendered catalogue order while saying nothing about it.

Placing and moving are **not** in this plan — the «¿Dónde va?» and «¿Qué juego va acá?»
sheets are plan 01.8.2-16, and Pendientes and Administrar estantes are plan 01.8.2-18. This
plan builds the page and its one job.

Output: the Estantes page's idle, searching and answered states, with the rail and the
pinned search.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| search input -> Shelves.search_copies/1 | staff-supplied free text reaches a database query |
| PubSub broadcast -> every open Estantes page | a message from another staff member's action mutates this page's render |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01.8.2-55 | Tampering | unbounded free-text search reaching the database | medium | mitigate | `search_copies/1` caps query length and result count following `CatalogFilters`' established 20x120 ceiling, and parameterises through Ecto — no string interpolation into SQL, no `String.to_atom/1` |
| T-01.8.2-56 | Denial of Service | an unbounded suggestion query over 435 games on every keystroke | medium | mitigate | the capped result count plus the existing indexes on the searched columns; the suggestion list is short by design (D-08 shows a handful, not a page) |
| T-01.8.2-57 | Tampering | a live broadcast moving the rail under a staff member mid-action | medium | mitigate | the rail re-reads only for the estante currently shown, scroll position is preserved for other estantes' broadcasts, and a change to the selected copy surfaces a quiet snackbar rather than a silent jump (D-11) |
| T-01.8.2-58 | Elevation of Privilege | the Estantes route reachable without staff | high | mitigate | the route stays inside `live_session :require_staff`; plan 01.8.2-01's signed-out redirect test still runs |
| T-01.8.2-59 | Information Disclosure | copy/estante location rendered on a public surface | high | mitigate | D-15's regression assertion added in plan 01.8.2-10 covers this for the rest of the phase |
</threat_model>
