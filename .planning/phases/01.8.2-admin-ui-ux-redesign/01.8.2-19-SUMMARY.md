# Phase 01.8.2 Plan 19: The Editor's Field Sheets Summary

**Two never-mixed sheet patterns — `.opt` + tick where choosing commits and closes (nivel, es una expansión) vs. a text field's own wide in-sheet `Guardar` where ✕ discards (nombre, descripción) — wired to four of the editor's seven editable blocks, plus the ⋮ menu's explicit handling of D-37's status-transition refusal tuples.**

## Accomplishments

- `choice_sheet/1` implements D-30's `.opt` + tick pattern for `nivel` (weight_band, exactly the
  three real `Vocabulary.weight_bands()` options) and `es una expansión` (Sí/No): the selected
  option carries a tick (`hero-check`), never the `--val` tint (D-23 — that tint stays on the row
  that opened the sheet); choosing calls `"choice-select"`, which writes into `@draft` and closes
  the sheet in one round trip; the sheet renders no `Guardar` anywhere.
- `text_sheet/1` implements D-30's other pattern for `nombre` and `descripción`: a wide in-sheet
  `Guardar` (`action/1` `anatomy="a1"`, widened via `.pk-editor-sheet-save`) runs the one changed
  field through `Catalog.change_game_admin/2` (built from the game's last-PERSISTED values, so an
  unrelated dirty field can never leak a spurious error) at commit time — valid input writes into
  `@draft` and closes; an error (e.g. the name's real `max: 255` cap) stays inline, in the sheet,
  never a page flash. A new `"sheet-input"` `phx-change` handler tracks `@sheet_value` live
  (separately from `@draft`) so ✕ genuinely discards typed-but-unsubmitted text, the actual defect
  073/079 found (T-01.8.2-88) — not just the trivial never-typed case.
- Every sheet commit — choice or text — writes ONLY into `@draft`; the plan's own most-important
  test re-reads the game from the repo after a sheet commit and confirms the old value is still
  persisted. Only the foot `save_bar/1`'s `Guardar` ever calls `Catalog`.
- The ⋮ menu now handles D-37's origin-guard refusal tuples explicitly via a new
  `lifecycle_error_message/1` (covering `:not_publishable`, `:not_retirable`, `:not_retired`,
  and a generic fallback), surfacing a snackbar (`put_flash`, routed through the shared
  `Layouts.admin_flash/1` per D-19c) instead of the old silent no-op. `status` still commits
  entirely outside `@draft`/`@saved`, verified directly: a status change with an in-progress,
  unsaved field edit leaves that edit and `dirty?` intact, and the franja re-renders the new
  consequence line.
- `test/pukllay_club_web/live/admin/game_live_test.exs` grew from 27 to 43 tests, all green under
  `mix test --warnings-as-errors`; `mix format --check-formatted`, `mix credo --strict`, and
  `mix compile --warnings-as-errors` all exit 0. The new CSS (`.pk-editor-opt*`,
  `.pk-editor-sheet-save`) was proven to reach `priv/static/assets/css/app.css` after
  `mix assets.build` (grep-verified, 1 occurrence each).
