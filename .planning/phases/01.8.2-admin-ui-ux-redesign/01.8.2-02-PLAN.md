<objective>
D-34's token reconciliation pass — the one early, pure-CSS slice that must run before any
admin UI slice. It diffs every custom property the admin sketches use against the shipped
`app.css`, lands the genuinely-new ones as real semantic tokens, maps the invented ones onto
real stops, and produces one table (`01.8.2-TOKENS.md`) the UI slices read from. It also
resolves D-33 (`--val` gets its own stop) and D-19o's press state, and settles the
"Sin guardar" dot colour left open under Claude's Discretion.

Purpose: sketch CSS is not transcribed on trust (D-34). Verified 2026-09-23 against the
shipped stylesheet: `--val`, `--color-surface-2`, `--stroke`, `--warn`, `--color-accent-bg`
and `--color-accent-text` have **zero** occurrences in `assets/css/app.css`, and
`-webkit-tap-highlight-color` has zero occurrences. Every admin slice after this one would
otherwise author classes against properties that resolve to nothing.

Output: `assets/css/admin/tokens.css` reached by the real build, an ExUnit gate binding the
tokens to their recorded values, and the mapping table.
</objective>
