### `lib/pukllay_club/catalog/seed/image_pipeline.ex` — `process_gallery/3` (service, transform)

**Analog:** the file's own `select_cover/1` (sibling function, same module) — no external analog needed, this is a targeted rewrite of one function.

**Current buggy implementation** (`image_pipeline.ex:68-91`, verbatim — this whole body is what gets replaced):
```elixir
@spec process_gallery(map(), String.t(), Credentials.t()) :: {:ok, [String.t()]}
def process_gallery(item, key_prefix, %Credentials{} = credentials) do
  cover_source_url =
    case select_cover(item) do
      {:ok, url, _source} -> url
      {:error, :no_image} -> nil
    end

  item
  |> Map.get(:versions, [])
  |> Enum.map(&Map.get(&1, :image))
  |> Enum.filter(&usable_image?/1)
  |> Enum.uniq()
  |> Enum.reject(&(&1 == cover_source_url))
  |> Enum.take(@max_gallery_images)
  |> Enum.with_index(1)
  |> Enum.reduce([], fn {source_url, index}, acc ->
    case upload_gallery_image(source_url, key_prefix, index, credentials) do
      {:ok, gallery_url} -> [gallery_url | acc]
      {:error, _reason} -> acc
    end
  end)
  |> then(&{:ok, Enum.reverse(&1)})
end
```

**Recommended fix pattern (per RESEARCH.md primary recommendation):** replace the body with `{:ok, []}` unconditionally, keep the `@spec`/typespec and function head identical (call sites in `catalog.seed.ex` and the new backfill task must not need signature changes). Do NOT touch `select_cover/1` (lines 49-58) or `spanish_version?/1` (line 93) — those are D-08's explicitly-protected, separately-tested code path. If `upload_gallery_image/4` (lines 105-113) becomes fully dead code after this change, leave it in place unless the planner explicitly decides to delete it (removal is optional cleanup, not required by any decision).

**Do not reintroduce:** any `Enum.map(&Map.get(&1, :image))` traversal over `:versions` without a `languages` gate — that absence is the entire bug.

### `lib/mix/tasks/catalog.backfill_gallery.ex` (new, utility/Mix task, batch)

**Analog:** `lib/mix/tasks/catalog.backfill_artists.ex` (full file, 41 lines) — copy this shape exactly, including the `--dry-run` flag, `Mix.Task.run("app.start")` call, and `dry_run_prefix/1` convention.

**Full analog** (`lib/mix/tasks/catalog.backfill_artists.ex:1-41`):
```elixir
defmodule Mix.Tasks.Catalog.BackfillArtists do
  @shortdoc "Fills games.artists from already-stored bgg_payload — no network I/O, safe to re-run"
  @moduledoc """
  ...
      mix catalog.backfill_artists [--dry-run]

  `--dry-run` scans and reports without writing to the database.
  """
  use Mix.Task

  alias PukllayClub.Catalog.Seed.StatsEnricher

  @impl Mix.Task
  def run(args) do
    {opts, _rest, _invalid} = OptionParser.parse(args, strict: [dry_run: :boolean])

    Mix.Task.run("app.start")

    dry_run? = Keyword.get(opts, :dry_run, false)
    summary = StatsEnricher.backfill_artists_from_payload(dry_run: dry_run?)

    Mix.shell().info(
      "#{dry_run_prefix(dry_run?)}Artists backfill complete: #{summary.updated}/#{summary.scanned} scanned, " <>
        "#{summary.deduplicated} row(s) had duplicated entries."
    )
  end

  defp dry_run_prefix(true), do: "[DRY RUN] "
  defp dry_run_prefix(false), do: ""
end
```

**Adapt for gallery backfill:** target name `Mix.Tasks.Catalog.BackfillGallery`; the underlying context function (see next section) should query `Game` rows `where: g.gallery_urls != []` (or `not is_nil` if that's the sentinel for "has stale data") and set `gallery_urls: []` via `Ecto.Changeset.cast/3` + `Repo.update/1`. Per RESEARCH.md, this needs **no `bgg_payload` read at all** — simpler than `backfill_artists_from_payload/1`, since the fix is "reset to empty," not "recompute from stored data."

### `lib/pukllay_club/catalog/seed/stats_enricher.ex` — add `backfill_gallery/1` (service, batch)

**Analog:** `backfill_artists_from_payload/1` in the same file (`stats_enricher.ex:99-108` doc + `:157-173` impl).

**Core pattern to copy** (`stats_enricher.ex:99-108`):
```elixir
@spec backfill_artists_from_payload(keyword()) :: map()
def backfill_artists_from_payload(opts \\ []) do
  dry_run? = Keyword.get(opts, :dry_run, false)

  games = Repo.all(from g in Game, where: not is_nil(g.bgg_payload), order_by: g.id)

  Enum.reduce(games, %{scanned: 0, updated: 0, deduplicated: 0}, fn game, acc ->
    apply_artists_backfill(game, dry_run?, acc)
  end)
end
```

**Per-row apply pattern** (`stats_enricher.ex:157-173`):
```elixir
defp apply_artists_backfill(game, dry_run?, acc) do
  raw = List.wrap(Map.get(game.bgg_payload || %{}, "artists"))
  deduped = BggClient.dedup_artists(raw)

  if !dry_run? do
    game
    |> Ecto.Changeset.cast(%{artists: deduped}, [:artists])
    |> Repo.update()
  end

  %{
    acc
    | scanned: acc.scanned + 1,
      updated: acc.updated + 1,
      deduplicated: acc.deduplicated + if(length(raw) > length(deduped), do: 1, else: 0)
  }
end
```

**Adapt for gallery:** query should filter `where: g.gallery_urls != []` (only rows that actually need a change — narrower than `backfill_artists`'s `not is_nil(bgg_payload)` since this fix doesn't need `bgg_payload` at all). Per-row apply becomes a straight `Ecto.Changeset.cast(%{gallery_urls: []}, [:gallery_urls]) |> Repo.update()` gated by `dry_run?`. Summary map should track `:scanned` and `:updated` (a `:deduplicated`-equivalent field isn't meaningful here — drop it or replace with something like `:already_empty` if useful for the console report).

**Error handling / idempotency pattern:** neither analog function has explicit try/rescue — errors surface via `Repo.update/1`'s own `{:ok, _} | {:error, changeset}` tuple, which callers of `backfill_artists_from_payload` do not currently pattern-match on (they assume success). Follow the same convention (no new error-handling machinery) unless the planner decides otherwise — this matches the module's stated "no batching/rate-limit/backoff needed" simplicity for payload-only backfills.
