# Phase 01.8.1 Plan 13: Band Audit (Revisar Niveles) Summary

**`Vocabulary.implied_weight_band/1` as the single reviewed-threshold source, `Catalog.BandAudit` (mismatches/correct/keep) with a drift-aware "keep" snapshot, and `/admin/niveles` completing the D-35 admin dashboard.**

## Accomplishments

- `Vocabulary.implied_weight_band/1` — the only function in the codebase allowed to state the
  weight-band thresholds (<1.9 Descubre el hobby, 1.9–3.1 inclusive Ingenio estratega, >3.1 Nivel
  experto); verified by a `grep` gate that no second threshold literal exists anywhere else in `lib`
- `games.band_reviewed_band` / `band_reviewed_at` snapshot columns + `Game.band_review_changeset/2`,
  and `Catalog.BandAudit` (`mismatches/0`, `count_mismatches/0`, `correct_band/1`, `keep_band/1`) —
  the mismatch comparison happens entirely in Elixir, never a second SQL copy of the thresholds
- `Admin.BandAuditLive` at `/admin/niveles`: lists every non-retired mismatched game with its
  current band, BGG weight, and BGG-implied band side by side; Corregir fixes the band in one tap,
  Mantener knowingly keeps it with drift detection (re-surfaces only if a later `bgg_weight` implies
  a different band than the snapshot); positive `Todo en orden…` empty state with no CTA when there
  are no mismatches
- Dashboard `Revisar niveles` card inserted fourth (Juegos, Estantes, Secciones, Revisar niveles,
  Staff), completing D-35's fixed card order, with a `badge-warning` `{N} discrepancias` count
  omitted at zero
