## Accomplishments

- `Game.admin_changeset/2` casts exactly `:name, :units, :weight_band, :is_expansion, :description` (D-07) — every BGG-derived fact stays read-only in the admin, enforced by the cast allowlist itself, not by convention.
- `Catalog.change_game_admin/2`/`update_game_admin/2` wrap that changeset for `Admin.GameLive.Form`, the new edit screen at `/admin/juegos/:id/editar`: form fields for the five club-owned columns, a read-only `CoreComponents.list/1` block for every BGG-derived fact (players, playtime, age, mechanics, themes, designers, artists, publishers, rating, rank, weight), and a status badge.
- `Catalog.list_admin_games/1`/`count_admin_games/1` back a new `Admin.GameLive.Index` at `/admin/juegos`: a `Todos/Borradores/Publicados/Retirados` filter row (patch-based, literal-clause `estado` parsing per T-01-37), a debounced name search with `%`/`_`/`\` ILIKE-escaping (T-01.8.1-23), a `phx-update="stream"` table, and `Cargar más` pagination (50-row pages) — never numbered pagination.
- Status lifecycle actions on the edit form: a draft's primary `Publicar` (a same-form submit button carrying `name="_action" value="publish"`, saving pending changes then calling `Catalog.publish_game/1` in one round trip); a published game's secondary `Retirar` behind a server-rendered `¿Retirar {juego}?` confirmation modal (no undo toast, per `ux-patterns` B11); a retired game's secondary `Restaurar`.
- The admin dashboard's `#admin-cards` grid gets its first card (D-35 order): `Juegos`, linking to `/admin/juegos`, with a `{N} borradores` `badge-warning` omitted at zero.
- `on_mount {PukllayClubWeb.UserAuth, :mount_current_scope}` added once to the `live_view` macro so every LiveView (public and admin) carries `@current_scope` — `CatalogLive.Index`, `CatalogLive.Show`, and `AboutLive` thread it into `Layouts.app`. `Layouts.header_inner/1` renders a staff-only `Admin` icon link before the search morph (hidden ≤480px via the new `.pk-nav-admin` CSS class, mobile staff use the drawer instead); `nav_drawer/1` gets a matching `Admin` row. `CatalogLive.Show` renders a staff-only `Editar` button above the game title, linking straight to that game's admin editor.
