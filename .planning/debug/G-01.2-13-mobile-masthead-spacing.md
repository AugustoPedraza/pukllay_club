## Resolution

root_cause: "Three independent CSS facts in assets/css/app.css, all present in the current mobile masthead (.pk-poster-col/.pk-poster-panel/.pk-gallery-dots), jointly produce the three symptom parts: (1) DOTS: .pk-gallery-dot's 44px WCAG touch-target button (lines 2648-2649) wrapping an 8px visible mark (2656-2658) with only a 4px inter-button gap (2634) yields a ~40px visual gap between marks — a touch-target-driven spread, not a gap-value bug. (2) FLOATING GROUPING: only the poster photo+gallery are wrapped in a bordered/shadowed 'card' (.pk-poster-panel, 2580-2589); the facts pills above it and the Reservar CTA (a spatially separate position:fixed bottom bar, #detail-cta-bar, since .pk-poster-reserve is display:none on mobile per 2615-2618) have no shared visual container binding them to the poster image, so each reads as an independent floating block — this was an explicit prior design decision (01.2-18/01.2-19 code comments) that reads as 'too disconnected' at the UAT bar. (3) MARGIN INCONSISTENCY: .pk-poster-panel's own padding: 1rem (2584) insets the poster photo an additional 16px beyond the shared --pk-gutter (14px at <=480px, 3434) that the facts pills and the CTA bar's wrapper are flush against — so the photo's effective left/right margin (30px) does not match the pills'/CTA's margin (14px) even though all three components technically live inside the same mx-auto w-full max-w-7xl pk-gutter shell."
