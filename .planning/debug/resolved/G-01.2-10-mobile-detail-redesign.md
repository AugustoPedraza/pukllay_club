## Resolution

root_cause: >
  Not a code defect — this is UI/UX design feedback on the mobile detail-page layout shipped by
  01.1-04 and gap-closed in 01.2-13 (buy-box panel + stacked CTA bar). Each of the 8 asks maps to
  a specific, already-identified artifact in
  `lib/pukllay_club_web/live/catalog_live/show.ex`'s `render/1`:
    1. Pills over poster — `GamePreview.facts_row` call (show.ex:371) sits as the FIRST element of
       `.pk-text-col`, which on mobile (`.pk-detail-masthead { grid-template-columns: 1fr }` below
       768px, app.css:2421-2428) stacks entirely BELOW the whole `.pk-poster-col` block, not
       over/beside it.
    2. Description not immediately after title — `weight_band_badge` (375-377) and
       `editorial_tags` (378-381) sit between `<h1>` (373) and the description block (383-394).
    3. Vertical space/CTA balance — the inline "Reservar" button inside `.pk-poster-col`
       (361-367) has no responsive hide and renders unconditionally on every viewport, DUPLICATING
       the already-fixed `.pk-mobile-cta-bar` (463-476, hidden only above 768px, app.css:
       2812-2814) on mobile — two CTAs competing for the same vertical budget the poster/
       thumbnails/title/pills need.
    4. "Type" pills — the Mecánicas (396-401) and Temáticas (403-408) `GameChips.chip_row` blocks
       render between the description and Ficha técnica, i.e. inside the "just title, description"
       zone the user wants clean.
    5. "Editoriales" — the Editorial/publishers `<dl>` row (424-427), gated by
       `ficha_tecnica?/1` (849-855), surfaces raw publisher names the user calls useless.
    6. No separator before similar games — the masthead and `CarouselRow.carousel_row` for
       "similares" (450-460) are plain siblings inside one `space-y-4` wrapper (310) with no
       divider/boundary treatment.
    7. Stacked share CTA — `#detail-cta-bar`'s `.pk-cta-bar-inner` (465-475) stacks the Reservar
       button (466-472) with a second `share_control` (`:bar` variant, 473) below it, duplicating
       the poster's own corner `share_control` (`:panel` variant, 314-316).
    8. Thumbnail strip vs. dots — `#gallery-thumbnails` (342-359) is a real, functioning
       image-switcher, not dead weight; replacing it with dots is an open product/design decision
       (dots alone don't provide a click target per image) rather than a defect to "fix".
  Additionally: `facts_row` has no distinct "age" pill (only jugadores/tiempo/dificultad) and
  `weight_band_badge` duplicates `facts_row`'s own dificultad fact — both flagged as open
  questions for the planner rather than confirmed defects.
