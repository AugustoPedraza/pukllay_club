## Resolution

root_cause: |
  THREE contributing conditions, all required together (AND-gated) — the image fit is NOT one of
  them; `.pk-about-map-thumb img` covers its box exactly (0px gap) at every viewport and theme.

  (1) CONTENT / PORT REGRESSION — `about_live.ex:556` ships sketch 048's 59-character DESKTOP
      caption ("Club de Emprendedores, San Salvador de Jujuy — Cómo llegar ↗") at every viewport.
      Sketch 048 defines a separate SHORT caption for its own 375px mobile frame ("Cómo llegar ↗",
      index.html:196) which was never ported. The long string wraps to 2 lines below 480px and to
      3 lines in the 640-767px column, taking `.pk-about-map-label` from 34px to 52px/70px.

  (2) CSS / TRANSLUCENT FLAT OVERLAY — `.pk-about-map-label` (app.css:2788-2797) uses
      `background: color-mix(in srgb, var(--color-base-100) 88%, transparent)` with
      `background-image: none` and no `backdrop-filter`. This was ported verbatim from a sketch
      where it sat over a FLAT GRADIENT PLACEHOLDER, never over a real image. Over the actual
      dense Maps screenshot, 12% transmittance lets street names, POI labels and park polygons
      read straight through — the user's "something shows through". The hard top edge (no scrim
      gradient) is the "looks cut off".

  (3) CSS / INVERSELY-COUPLED SIZING — `.pk-about-map-thumb`'s `aspect-ratio: 21/9`
      (app.css:2774) ties box HEIGHT to box WIDTH, while the caption's height is unconstrained
      and content-driven (no max-height, no line-clamp, no white-space:nowrap). The parent band's
      `sm:grid-cols-2` (about_live.ex:528) halves the card's width at exactly 640px. So as width
      shrinks the box gets SHORTER while the caption gets TALLER — coverage explodes
      superlinearly, from 15.1% at 639px to 74.9% at 640px across a single pixel.
