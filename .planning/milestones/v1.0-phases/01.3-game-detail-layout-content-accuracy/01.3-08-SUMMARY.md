# Phase 01.3 Plan 08: Description Justify + Inline Icon-Only Toggle Summary

**Justified the game description at every viewport width and replaced the detached "Ver más" text link with sketch 042's inline icon-only chevron, rendered from `@description_expanded` via two mutually exclusive `:if` branches — no client-side DOM relocation, no colocated hook.**

## Performance

- **Duration:** ~55 min
- **Tasks:** 3/3 completed
- **Files modified:** 3 (`show.ex`, `app.css`, `catalog_show_test.exs`)

## Accomplishments

- Renamed `.pk-clamp` to `.pk-desc`, declaring one shared `line-height:
  1.5` that every derived value (`.pk-desc.is-clamped`'s `max-height`,
  `.pk-desc-toggle`'s `margin-top`) reads as a `calc()` multiple, never an
  independent literal. `text-align: justify` is unconditional at every
  width (UAT item 6); `text-justify: inter-word` is pinned as load-bearing
  on the clamped line per `description-truncation.md`.
- Replaced the `-webkit-line-clamp` clip mechanism with `max-height` +
  `overflow: hidden` — avoids the round-17 crash (an interactive button
  nested inside a `-webkit-box` paragraph) sketch 042 hit. Removed the
  stale 480px `.pk-clamp { -webkit-line-clamp: 2; }` mobile override,
  which is now dead weight (the new clip is a fixed line-height multiple,
  identical at every width by construction).
- Rewrote the description block into two mutually exclusive `:if`
  branches off `@description_expanded`: collapsed renders the toggle as
  the paragraph's first child, floated right with a 2-line-height
  `margin-top` so text wraps around it starting on the 3rd/clipped line;
  expanded renders the same toggle as a trailing sibling after the full
  paragraph. This is the LiveView-native equivalent of sketch 042's JS
  `toggleDesc()` DOM relocation — no colocated hook added or needed.
- `aria-expanded`/`aria-controls="game-description"`/`aria-label` ("Ver
  más"/"Ver menos") carry state to assistive tech; the visible control is
  icon-only (an `aria-hidden` ellipsis span + `hero-chevron-down`/`-up`).
  `.pk-desc-toggle::before`'s `-13px` symmetric inset clears the 44px
  touch floor without changing the ~24x18px visible footprint.
- Re-pinned the one stale `pk-clamp`-referencing test and added a new
  describe block: initial collapsed render, single-toggle expanded render
  (button relocates to trailing sibling, ellipsis disappears), a
  three-cycle round-trip test (six transitions — the exact regression
  class sketch 042 hit), a nil-description render (neither paragraph nor
  toggle), and four CSS-source pins (justify/inter-word, no line-clamp
  survives in the description family, shared line-height multiple,
  `::before` inset magnitude).
