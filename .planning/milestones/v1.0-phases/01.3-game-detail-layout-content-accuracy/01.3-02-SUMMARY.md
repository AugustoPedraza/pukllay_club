### Investigated, Not a Deviation

**1. Task 1's acceptance criterion `bgg_payload ? 'artists' AND array_length(artists,1) IS NULL`
returned 8, not 0**
- **Found during:** Task 1 acceptance-criteria verification
- **Investigation:** `array_length()` in Postgres returns `NULL` for a legitimately empty array
  (`'{}'`), not `0` — a documented Postgres quirk. Direct inspection confirmed all 8 flagged rows
  have `bgg_payload->'artists' = '[]'::jsonb` (BGG itself returned zero artist links for those
  games — e.g. Minecraft: Builders & Biomes, Marvel Champions: The Card Game, Little Secret).
  `377 (non-empty artists) + 8 (legitimately-empty artists) = 385 = every game scanned` — no game
  was skipped.
- **Resolution:** No code change. This is a false-positive in the acceptance criterion's literal
  SQL, not a defect in `StatsEnricher.backfill_artists_from_payload/1`. Documented here per the
  plan's own instruction ("If a criterion cannot be satisfied after 2 fix attempts, log it as a
  deviation with reason — do NOT silently skip it").
- **Verification:** `SELECT count(*) FROM games WHERE bgg_payload->'artists' = '[]'::jsonb` → 8;
  `SELECT count(*) FROM games WHERE bgg_payload ? 'artists'` → 385.
