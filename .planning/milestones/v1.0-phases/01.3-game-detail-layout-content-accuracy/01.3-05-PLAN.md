visual halves.

There is nothing left to decide here. `01.3-CONTEXT.md` routed the open-ended visual call to
`/gsd-ui-phase` rather than to blind planning, mirroring how Phase 01.2 handled its buy-box redesign,
and the resulting contract is approved with all six checker dimensions passing. It supplies the exact
CSS, the exact markup and the exact Spanish copy. This plan is implementation and test coverage.

The diagnosis the contract is built on, grounded in the shipped stylesheet: the reading column is a
flex column with one flat sixteen-pixel gap applied uniformly between every child, so a heading and
the content it introduces sit exactly as far apart as the end of one topic and the start of the next.
Nothing currently signals "new topic starts here" more strongly than "next line of the same
paragraph." The fix is a two-tier rhythm — eight pixels inside a section, thirty-two between them —
plus one new wrapper class, one heading-style change and one new group label. No new visual language,
no new component, no restructure.

Purpose: this is the change a member actually sees, and the reason the phase exists.
Output: a reading column with real hierarchy, an Ilustradores row, and a labelled Avanzado stats
group — all covered by tests, all backed by the real data plans 01.3-02 and 01.3-04 populated.
