# Phase 01.3 Plan 07: Reading-Column Recomposition (Fact Grid + Comunidad BGG) Summary

**Recomposed the detail page's reading column to title -> hashtags -> description -> one unheaded two-column fact grid -> Comunidad BGG block (sketches 039-043), closing six items of UAT gap G-01.3-1 with a new `creator_pills/1` component, retoned pill CSS, and a fully re-pinned test suite.**

## Performance

- **Duration:** ~100 min (estimate — no exact start timestamp was recorded at
  session start)
- **Tasks:** 3/3 completed, plus 2 small follow-up commits (a comment-wording
  fix and the addition of 3 net-new CSS-source tests task 3's own action list
  required but the initial commit omitted)
- **Files modified:** 5 (4 in the plan's `files_modified`, plus
  `game_chips_test.exs` as a Rule 1 fallout fix)

## Accomplishments

- Recomposed `.pk-text-col`'s entire body: title (its own `.pk-reading-section`)
  → editorial hashtags (`class="pk-rhythm-8"`, no wrapper) → description
  (`.pk-reading-section.pk-rhythm-16`) → one unheaded fact grid
  (`.pk-reading-section.pk-rhythm-16`, containing Año + a `.pk-fact-cols`
  2x2 grid for Diseñadores/Ilustradores/Mecánicas/Temáticas) → Comunidad BGG
  (`.pk-reading-section.pk-rhythm-32`). Deleted the reading-column divider,
  both Mecánicas/Temáticas `<h2>`s, the Ficha técnica `<h2>`, the minimum-age
  row, and the old `pk-spec-group-label` "Avanzado" element.
- New `creator_pills/1` private function component (beneath `share_control/1`)
  renders Diseñadores/Ilustradores as `pk-pill pk-pill-outline
  pk-pill-interactive` links to `/?designers=`/`/?artists=` — the `~p` sigil
  percent-encodes the interpolated name, so a space- or accent-bearing name
  never needs manual encoding.
- `ficha_tecnica?/1` replaced by `fact_grid?/3(game, mechanic_labels,
  theme_labels)` (year/designers/artists/mechanic_labels/theme_labels) and a
  new `comunidad_bgg?/1` (`advanced_stats?/1` or `bgg_id`) — `bgg_id` left the
  fact-grid guard entirely, now gating only the Comunidad BGG block.
- CSS: `.pk-text-col`'s flex `gap` replaced by three named child-margin rhythm
  rules (`.pk-rhythm-8/16/32`, same edit that removed the gap — never both
  declared, the additive-boundary bug `detail-page-layout.md` records twice);
  `.pk-fact-cols` single-column base + two-column override inside the existing
  single 48rem block; `.pk-fact-col dt/dd`; `.pk-spec-group-label` removed;
  new `.pk-pill-tag` tone (transparent, `--color-primary` text, measured
  14.4:1 light / 6.0:1 dark against `--color-base-100`); new
  `.pk-bgg-label/-row/-stat/-num/-lbl/-foot`.
- `GameChips.chip_row/1` retoned neutral→outline; `GameChips.editorial_tags/1`
  retoned accent→tag plus a new optional `class` attr so `show.ex` can pass
  `pk-rhythm-8` without an extra wrapper element. `GamePreview.facts_row/1`
  deliberately untouched — the masthead stays closed per the Phase 01.3
  roadmap goal, recorded as a known neutral-vs-outline inconsistency.
- Re-pinned the entire detail-page test suite against the new composition:
  inverted order assertions, replaced dead sibling-chain selectors, re-targeted
  Ilustradores/Avanzado assertions at the new structure, added a
  space+non-ASCII round-trip test through `CatalogFilters.from_params/1`, and
  added the fact-grid-breakpoint / additive-boundary / hashtag-contrast
  CSS-source pins task 3's own action list required.
