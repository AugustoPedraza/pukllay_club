# Phase 01.3 Plan 01: Tracer + Offline Write Path Summary

**Wires BGG's average rating through SweetXml extraction, a two-column-plus-artists migration,
and a rendered "Valoración BGG" spec row, then builds the narrow offline write path (StatsEnricher
+ two Mix tasks) that will populate all ~400 games in 01.3-02.**

## Performance

- **Duration:** 55 min
- **Started:** 2026-08-30T21:04:00Z (approx.)
- **Completed:** 2026-08-30T21:59:23Z
- **Tasks:** 2
- **Files modified:** 11 (6 created, 5 modified)

## Accomplishments

- `BggClient.parse_items/1` now extracts `average_rating` (SweetXml `fo`) and `rank` (SweetXml
  `Io`, discriminated by `@name='boardgame'`), passed through a new `normalize_item/1` hook that
  applies `dedup_artists/1` (public, shared) and `zero_to_nil/1` (private) to every parsed item —
  so `mix catalog.seed` inherits the fix automatically, with no separate normalization pass needed.
- New migration adds `games.artists`/`games.bgg_rating`/`games.bgg_rank` and normalizes the 2
  pre-existing `bgg_weight = 0` rows to `NULL`; `Game.seed_changeset/2` casts all three new fields.
- `CatalogLive.Show` renders a conditional "Valoración BGG" row (`:if={@game.bgg_rating}`) between
  Diseñadores and the existing BoardGameGeek outbound link, formatted via `format_bgg_rating/1`
  (`:erlang.float_to_binary/2`, no new dependency) and linking to the game's BGG page.
- `StatsEnricher.enrich_from_bgg/2` and `StatsEnricher.backfill_artists_from_payload/1` provide the
  offline write path for D-05/D-06, both writing through a narrow `Ecto.Changeset.cast/3`
  allowlist and never touching `ImagePipeline` or the full-row upsert helper.
- `mix catalog.enrich_bgg_stats` and `mix catalog.backfill_artists` are runnable, documented Mix
  tasks; a live dry-run of the artists backfill against `pukllay_club_dev` confirmed 385 games
  scanned, 368 with duplicated artist entries, and zero rows changed.

## Decisions Made

- Rank discriminated by BGG's `@name='boardgame'` attribute rather than `@type`, per plan guidance
  (BGG applies `@type` inconsistently across overall/subdomain ranks; `@name` is stable).
- `zero_to_nil/1` pattern-matches `+0.0` explicitly rather than bare `0.0`, avoiding an
  Elixir/OTP 27+ float-matching compiler warning that would otherwise fail
  `--warnings-as-errors`.
- Reworded `stats_enricher.ex`'s moduledoc to avoid the literal substring `upsert_game` in prose
  (referring instead to "the full-row-upsert helper") so the plan's own acceptance-criteria grep
  gate (`grep -c "upsert_game" ... returns 0`) doesn't false-positive on documentation text.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed OTP 27+ float pattern-match warning in `zero_to_nil/1`**
- **Found during:** Task 1, `mix ecto.migrate` (dev) compile step
- **Issue:** `defp zero_to_nil(0.0), do: nil` triggered "pattern matching on 0.0 is equivalent to
  matching only on +0.0 from Erlang/OTP 27+" under `mix compile --warnings-as-errors`.
- **Fix:** Changed the clause to `defp zero_to_nil(+0.0), do: nil`, matching Erlang/OTP 27+'s
  explicit sign convention.
- **Files modified:** `lib/pukllay_club/catalog/seed/bgg_client.ex`
- **Verification:** `mix compile --warnings-as-errors` exits 0.
- **Committed in:** `c861dc0` (Task 1 commit)

**2. [Rule 1 - Bug] Reworded `stats_enricher.ex` moduledoc to pass its own grep gate**
- **Found during:** Task 2, running the plan's `grep -c "upsert_game" ...` acceptance check
- **Issue:** The moduledoc's prose explicitly named `PukllayClub.Catalog.upsert_game!/1` to explain
  why the module avoids it — which itself matched the literal grep pattern the acceptance
  criterion checks, producing a false-positive "1" instead of the required "0".
- **Fix:** Reworded the sentence to say "the full-row-upsert helper in `PukllayClub.Catalog`"
  instead of naming the function literally.
- **Files modified:** `lib/pukllay_club/catalog/seed/stats_enricher.ex`
- **Verification:** `grep -c "upsert_game" lib/pukllay_club/catalog/seed/stats_enricher.ex` returns 0.
- **Committed in:** `64d5e83` (Task 2 commit)
