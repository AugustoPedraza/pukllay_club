# Phase 01.3 Plan 10: Native Line-Clamp Toggle (Gap Closure G-01.3-4) Summary

**Closed UAT gap G-01.3-4 by moving the description's expand/collapse chevron entirely out of the paragraph's line box — replacing the float-inside-a-justified-clamped-paragraph technique with a native three-line clamp plus an always-trailing-sibling toggle, so the chevron's containment is a DOM-structure guarantee no rendering engine can violate.**

## Performance

- **Duration:** ~35 min
- **Tasks:** 2/2 completed
- **Files modified:** 3 (`app.css`, `show.ex`, `catalog_show_test.exs`)

## Accomplishments

- Replaced `.pk-desc.is-clamped`'s `max-height` + `overflow: hidden` clip
  with the native `display: -webkit-box; -webkit-box-orient: vertical;
  -webkit-line-clamp: 3; overflow: hidden; text-overflow: ellipsis;` recipe
  — the only clip mechanism with a native clean-cut guarantee, per
  `description-truncation.md`.
- Collapsed `.pk-desc-toggle` to a single rule positioned purely by
  `.pk-desc-shell`'s flex column (`align-self: flex-end`) — deleted the
  `float`, `clear`, `position: relative`, and the two-line-height
  `margin-top` offset that depended on the toggle living inside the
  paragraph's line box. Also deleted the now-dead `.is-trailing` modifier,
  the invisible `::before` hit-area pseudo-element, and the
  `.pk-desc-toggle-ellipsis` rule (no ellipsis span survives — the native
  clamp supplies its own).
- `show.ex`'s description block collapsed from two mutually exclusive `:if`
  branches (button nested first-child when collapsed, trailing sibling when
  expanded) to ONE paragraph and ONE always-trailing-sibling button, both
  driven by `@description_expanded`. `aria-expanded` is now an explicit
  `to_string/1` conversion (HEEx would otherwise drop a bare `false` as an
  absent boolean attribute); the icon name is chosen between two complete
  string literals so Tailwind's content scanner still finds both.
- Per the plan's own `<planner_note>` departures: the toggle carries a REAL
  44x44px box via `min-h-11 min-w-11` (the `.pk-scroll-top` idiom) instead
  of the deleted invisible offset overlay, and the icon steps 12px → 16px
  (`.pk-scroll-top`'s `size-4`) since the ellipsis glyph it was ink-aligned
  to no longer exists.
- Re-aimed every existing description test to the sibling-toggle structure,
  inverted the two CSS-source pins that asserted the old float/max-height
  mechanism, and deleted the now-obsolete `::before` hit-area inset test.
  Added three net-new regression tests (Task 2): the toggle is never a
  descendant of the paragraph in either state, the toggle's class carries
  the real touch-floor utilities, and no rule anywhere in the `.pk-desc*`
  family declares float-based positioning.
