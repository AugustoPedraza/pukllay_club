## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed `--only-english`'s stale-payload resumability filter**
- **Found during:** Task 2, while running the full batch (after the first `--limit 60` and `--only-english --limit 150` invocations completed with suspiciously low candidate counts)
- **Issue:** `maybe_filter_only_english/2` compared `game.description` against an exact string match of `DescriptionNormalizer.clean(bgg_payload["description"])`. `01.3-02`'s BGG re-enrichment task independently refreshes `bgg_payload` on its own schedule (narrow changeset, `description` column untouched), so BGG's own description text for a game can legitimately drift between when `games.description` was first seeded and when this job runs. Any game where that drift occurred looked "already translated" to the exact-match check even though it was still plain English — confirmed 214/385 real candidates affected, reconciling exactly with `60 (batch 1) + 111 (batch 2, genuine matches) + 214 (wrongly excluded) = 385`.
- **Fix:** Replaced the exact-match check with a `>=2`-distinct-marker check against a curated list of common English function words (`and, your, you, with, this, that, are, which, will, from, have, been, into, their` — deliberately excluding "the", which survives inside preserved English game titles like "The Gallerist" often enough to cause false positives at a 1-marker threshold).
- **Files modified:** `lib/mix/tasks/catalog.translate_descriptions.ex`
- **Verification:** Ran the fixed filter as a dry script against the live DB before touching the real batch — confirmed exactly 214 candidates (matching the reconciled math) with zero false positives against the 5 already-known-translated samples. `mix compile --warnings-as-errors`, `mix test` (679/679), `mix format --check-formatted`, `mix quality` all pass.
- **Committed in:** `4709334`
