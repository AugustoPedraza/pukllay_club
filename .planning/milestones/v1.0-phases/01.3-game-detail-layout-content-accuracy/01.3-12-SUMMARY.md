# Phase 01.3 Plan 12: Collapsed Chevron Last-Line-Band Anchor (Gap Closure G-01.3-6) Summary

**Closed UAT gap G-01.3-6 by replacing the collapsed toggle's flex-column/align-self placement with a `:not(.is-expanded)`-scoped absolute overlay anchored on `.pk-desc-shell`'s own box — seating the chevron's 16px icon in the clamped paragraph's last 24px line band instead of on a block row below the whole paragraph — and pinned the fix with a derived-contract geometry test that was proven to fail against the pre-fix stylesheet.**

- **Completed:** 2026-08-31T22:54:42-03:00

## Accomplishments

- `.pk-desc-shell` gained `position: relative` (the positioning context the
  collapsed override anchors against) and a new `:not(.is-expanded)`-scoped
  `min-height: 2.75rem` floor so a short (sub-three-line) description cannot
  let the overlay hang upward over the hashtag row above.
- `.pk-desc.is-clamped` gained `padding-right: 2.75rem` — exactly the
  toggle's `min-w-11` markup box, not the smaller 16px icon — reserving the
  full interactive tap area's footprint so no clipped text or ellipsis ever
  renders under it.
- A new `.pk-desc-shell:not(.is-expanded) .pk-desc-toggle` rule is the actual
  fix: `position: absolute; right: 0; bottom: 0; align-items: flex-end;
  padding-bottom: 0.25rem` takes the collapsed control out of the shell's
  flex column (the root cause — a column-direction flex container can only
  ever give a sibling its own row, never pull it up into a prior sibling's
  last line box) and seats the 16px icon's ink at 52-68px in the 72px-tall
  3-line clamp box, centred in the 48-72px last line band.
- The expanded state's rules are byte-identical to what 01.3-10 shipped;
  `align-self: flex-end` stays declared on the base `.pk-desc-toggle` rule
  and still governs that state.
- Both `.pk-desc-shell`'s and `.pk-desc-toggle`'s doc comments were rewritten
  to state which rule governs which state, per this stylesheet's own
  comment-accuracy convention (01.3-10 precedent).
- A new `collapsed toggle geometry (01.3-12)` describe block in
  `catalog_show_test.exs` (6 tests) computes the toggle's ink band and
  horizontal/vertical reservations from the stylesheet's own declarations —
  the derived-contract oracle pattern from `footer_rhythm_test.exs` — and
  was demonstrated to fail (5 of 6 tests) against the pre-Task-1 stylesheet
  before being demonstrated to pass against the committed one.
