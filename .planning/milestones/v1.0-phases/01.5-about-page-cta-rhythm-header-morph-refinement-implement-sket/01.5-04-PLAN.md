<objective>
Finish the page-wide CTA rhythm: stop the closing band from duplicating the Sumate ask at the width
where the sticky bar takes over, and alternate plain/tinted band backgrounds down the whole page.

Purpose: these are the two remaining sketch-051 findings that operate on the page as a whole rather
than on one band. D-11 closes the "same ask twice on one screen" problem at the one width where the
sticky bar and the closing button coexist, without opening the opposite problem (a width with a
hidden button and no bar either). D-14 gives adjacent sections visible separation so each one reads
as its own moment, while leaving the FAQ's dark band alone as the page's single bold stop.

This is the phase's last plan, so its final task also carries the whole-phase gate: full suite,
asset build, the developer-invoked visual probe, and the end-of-phase visual walkthrough.

Output: a new `.pk-band-tint` class applied to two sections, one added rule inside the existing
`@media (max-width: 480px)` block, a stable class on the Cierre button wrapper, and new tests for
both.
</objective>
