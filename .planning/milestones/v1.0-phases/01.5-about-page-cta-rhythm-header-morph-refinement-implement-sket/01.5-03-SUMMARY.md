# Phase 01.5 Plan 03: Cierre Signature Cleanup, One-Gap Rhythm & Full-Screen Desktop Summary

**The Cierre closing band's signature is now a plain, link-free two-line mobile wrap; its entire internal spacing comes from one flex gap; and on desktop it fills the viewport with padding compensated against the header's own live published height.**

## Performance

- **Duration:** ~55 min
- **Started:** 2026-09-08T06:20:00-03:00 (approx, worktree spawn + reading)
- **Completed:** 2026-09-08T07:15:00-03:00
- **Tasks:** 3
- **Files modified:** 3

## Accomplishments
- Deleted the Cierre signature's trailing `<a href={ClubLinks.instagram_url()}>Instagram</a>` — shipped since plan 049 and flagged "for developer review" in the moduledoc — because Contacto's 3-channel chip row (plan 01.5-02) now makes it redundant (D-13). `#cierre` now contains exactly one anchor: the Sumate button.
- Reshaped the signature to `Pukllay Club ·<br class="pk-about-closing-break" /> San Salvador de Jujuy, Argentina`, wrapping to two centered lines on mobile at the natural "·" break point via a new `.pk-about-closing-meta` class sized by an id+class selector (`#cierre .pk-about-closing-meta`, specificity 1,1,0) so no shared type+class rule can silently out-specify it — the exact fix for sketch 051's own thirteen-round cascade bug.
- Added `#cierre .pk-band-inner { display: flex; flex-direction: column; align-items: center; gap: 1.5rem; }` as the band's first and only internal spacing mechanism (D-12) — previously the heading/button/signature had zero declared spacing between them. `text-center` stays in the markup untouched so the two-line signature's shorter line stays centered.
- Added a `@media (min-width: 640px)` block making `#cierre` a full-viewport moment (`min-height: 100vh`, flex-centered, `padding: var(--pk-header-h, 4.5rem) 0 0`) with the heading scaled to `clamp(2rem, 4vw, 3rem)` — desktop-only; mobile keeps the compact shared `.pk-band` treatment (D-10).
- Full test suite (872 tests) passes; `mix compile --warnings-as-errors`, `mix format --check-formatted`, and `mix assets.build` all clean.

## Decisions Made
- Kept `.pk-about-eyebrow` and `.pk-about-eyebrow a` byte-identical apart from one added comment, rather than deleting the now-technically-unused `a` rule — it remains a general class that may gain a future link-bearing consumer, and deleting a rule solely because its one current caller stopped using it is the exact "audit only the changed property" mistake sketch 051's third bug documents.
- Placed the new mobile size rule (`#cierre .pk-about-closing-meta`) inside the SAME pre-existing `@media (max-width: 639px)` block plan 01.5-02 created for the Contacto chips, rather than opening a second block at the identical breakpoint — one block per breakpoint, consistent with this file's own established convention.
- Placed the new `#cierre .pk-band-inner` gap rule and the `@media (min-width: 640px)` full-screen block adjacent to the Cierre signature rules (`.pk-about-eyebrow`/`.pk-about-closing-break` cluster), not scattered elsewhere in the file, so all of Cierre's own CSS lives together.
