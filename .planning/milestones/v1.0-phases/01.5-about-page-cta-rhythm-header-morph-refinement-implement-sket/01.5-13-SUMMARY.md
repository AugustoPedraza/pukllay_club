## Decisions Made

- **Both levers shipped together, in the same media block and same task.** The diagnosis's ten-case mutation matrix showed no single-variable lever moves both pad/content and sig/h2 into range — shipping one alone would close half the report, which on this band's four-round UAT history is how a gap reopens rather than closes.
- **Padding: `2.5rem`** (0.851 measured, inside the 0.90-1.02 desktop-derived range with headroom). Runner-up `3rem` recorded by name in the CSS comment (measured 1.12 alone / 1.02 with the heading step) for a one-value retune if the walkthrough finds 2.5rem cramped.
- **Heading: `32px`/`40px`** — exactly what the existing desktop clamp already resolves to at the 640px gate, continuing the band's own size ramp rather than inventing a value. 30px was measured as an exact 0.999 tie (no hierarchy at all), so 32px is the smallest step that actually inverts the relationship.
- **The mobile invariance oracle is re-derived, not re-pinned** — its expected height now comes from `#cierre`'s own computed padding, read live, with no literal anywhere in the function. The even-split assertion (the only guard against asymmetric padding) is unchanged.
- **The proportion check's budget is captured live from this SAME run's own desktop measurement**, via one dedicated pre-pass case before the sweep — both sides move together on any future desktop retune, the same principle `checkCierreRunRatioBudget` already established one level up for a same-case comparison, extended here to a cross-case one.
- **The desktop block's carrier-sentence comment is corrected, not deleted** — it claimed "its larger heading" as a co-carrier of Cierre's distinctness, which was false below 640px until this plan. Now true at both regimes, with a two-way cross-reference between the two blocks, per the plan's own explicit instruction.
- **The gap, the caption's 10px override, and the forced `<br>` were all deliberately left untouched** — the prior debug session measured each of them making one or both complaints WORSE (E-07: gap tightening moves pad/content backwards to 1.85/1.95; raising the caption to 12px moves sig/h2 to 1.498; dropping the `<br>` yields sig/h2 1.792). This plan's own CSS comment records these refuted levers by name.
