# Plan 01-04 — Full 434-game seed: data-quality rules, gallery, search indexes

**Phase goal (verbatim from ROADMAP.md):** Members can browse, filter, sort, and search a public
catalog of ~400 games, with UX that teaches complexity instead of assuming hobbyist vocabulary.

> **Expansion of the 01-03 tracer.** The tracer proved one game along the whole path. This plan
> widens that same path to the real 434-row file, adds the messy-data rules the real export actually
> requires, adds the gallery and Spanish-cover preference, and lays the search/facet indexes on top
> of the loaded data.

<objective>
Load the club's entire real catalog with the data-quality handling the real file demands, and make
it searchable.

Purpose: 01-CONTEXT.md D-16 through D-20 are the results of auditing the actual `ludoteca.csv` —
inconsistent `si`/`Sí`/`sí` casing plus stray typo cells, 11 games with two weight bands marked at
once, 46 with none, 41 with no BGG id at all, and one duplicated BGG id. 01-RESEARCH.md Pitfall 3b
is explicit that assuming clean input will silently corrupt the seed. Every one of those cases gets
an explicit branch and, where it cannot be resolved from data, a line in a review report rather than
a guess.

Output: 434 game rows, two-variant club-hosted images plus a small gallery per enriched game, an
accent-folding Spanish search vector with its GIN indexes, a committed manual-review report, and a
runbook for the one-time production run.
</objective>

  `ALTER TABLE games ADD COLUMN search_vector tsvector GENERATED ALWAYS AS (to_tsvector(

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BGG XML response → parser (now including `versions` sub-items) | A wider slice of untrusted external XML is parsed. |
| BGG-supplied version image URLs → server-side fetch | ~4x more externally-sourced URLs are fetched than in the tracer. |
| developer machine → production Postgres over SSH tunnel | The one-time production seed crosses the network with database write access. |
| seed report → committed repository (public) | Report content is world-readable once committed. |
