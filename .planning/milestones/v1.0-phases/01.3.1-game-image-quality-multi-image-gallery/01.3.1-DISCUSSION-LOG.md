## Pre-discussion finding (not a question — codebase/data investigation)

Before presenting gray areas, investigated the user's stated problems against the actual
codebase and live data:

- Multi-image gallery (up to 3 images) and Spanish-edition cover preference were found to
  **already exist** (`ImagePipeline.select_cover/1`, `process_gallery/1`, Phase 1; lightbox
  display, Phase 01.2) — not new work.
- Downloaded and visually inspected the actual stored images for Endless Winter: Paleoamericans
  (BGG id 305096): `cover_url` is the correct Spanish/Fantasía edition; `gallery_urls[0]` is the
  Taiwanese/Chinese-language edition (Broadway/栢龍玩具). Confirmed root cause:
  `process_gallery/1` sources "extra images" from other BGG version box covers (any language),
  with no language filter — a pipeline bug affecting any game with 2+ international editions,
  not a data anomaly specific to one game.
- Found the fixed near-square `.pk-card-poster { aspect-ratio: 1 / 1.05; }` + `object-cover`
  crop applied to all box art regardless of native proportions — confirmed unaddressed.

This reframed the phase from "build multi-image + language-aware sourcing" to "fix what the
gallery contains, fix how box art scales, backfill the existing catalog."
