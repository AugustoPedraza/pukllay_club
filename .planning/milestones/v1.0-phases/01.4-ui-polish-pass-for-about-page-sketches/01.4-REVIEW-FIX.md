## Fixed Issues

### CR-01: Isologo dock position collapses to a zero-size rect in dark theme

**Files modified:** `lib/pukllay_club_web/live/about_live.ex`
**Commit:** fb1b532
**Applied fix:** Replaced the single `querySelector(".pk-brand-mark")` call in `dockRect()`
(which always returned the first, light-theme `<img>` regardless of active theme) with a
`querySelectorAll` walk that returns the first mark with a non-zero layout rect, falling back to
the first match if neither mark has been laid out yet. This matches the fix suggested in
REVIEW.md verbatim, applied to the current source (no drift from the reviewed state).

### WR-01: Photo carousel autoplay can never resume after a touch interaction

**Files modified:** `lib/pukllay_club_web/live/about_live.ex`
**Commit:** 991a22d
**Applied fix:** Added a `resumeTimer` alongside the existing `paused` flag. `onPointerDown`
(which fires on touch swipes and dot taps, unlike `mouseenter`/`mouseleave`) now sets `paused =
true` and schedules a 6s timer that resets `paused = false`, giving touch users the same
"autoplay resumes after you stop interacting" behavior mouse users already get from
`mouseleave`. `onMouseEnter`/`onMouseLeave` were updated to clear the pending timer so the two
mechanisms don't race each other, and `destroyed()` now clears the timer too. Verified
`onPointerDown` already fires before `onClick` on dot taps, so the dot-click path is covered by
the same fix without a separate change to `onClick`.

### WR-02: Header is hidden via `opacity: 0`/`pointer-events: none` but stays keyboard/screen-reader reachable

**Files modified:** `lib/pukllay_club_web/live/about_live.ex`
**Commit:** ac79660
**Applied fix:** Added `inert` to `#app-header` at the same point `pk-header-about-morph` is
added in `mounted()` (the hidden-by-default state), removed it in the first-paint branch when
the visitor lands already docked (visible), toggled it alongside `is-docked` in `syncPosition()`
on every dock-state flip (`toggleAttribute("inert", !this.docked)`), and removed it in
`destroyed()` alongside the existing class cleanup — mirroring the drawer/cat-menu `inert`
pattern already established elsewhere in `layouts.ex`.
