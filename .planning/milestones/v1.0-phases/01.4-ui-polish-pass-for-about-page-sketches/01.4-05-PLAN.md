<objective>
Implement sketch 045: on the About page the shared header starts fully hidden, the club's isologo
fades in inside the hero about half a second after load, tracks scroll one-to-one like ordinary
content, and snap-morphs into the header's compact brand mark at the precise geometric point where

landing page rather than another catalog route. It is also the riskiest work in the phase, which is
why it is sequenced last: the four preceding plans ship real content and truth fixes that must not
be held hostage to a motion effect.

Output: a page-owned `.AboutHeaderMorph` colocated hook, a floating mark and its in-flow spacer, a
suppression hook class on `brand_logo/1`'s isologo images, About-scoped CSS for the hidden and
docked header states, structural tests, and a live CDP verification pass.
