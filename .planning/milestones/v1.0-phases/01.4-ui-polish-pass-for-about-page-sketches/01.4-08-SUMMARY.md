# Phase 01.4 Plan 08: Isologo Clear-Space Derivation Summary

**Derived the About hero's isologo clear space from the approved sketch (80px = 44.4% of a reconciled 180px mark) instead of an intuition-picked mb-8, and fixed the hero's inverted above/below allocation.**

## Performance

- **Duration:** ~20 min
- **Completed:** 2026-09-04
- **Tasks:** 2/2 completed
- **Files modified:** 3 (assets/css/app.css, lib/pukllay_club_web/live/about_live.ex, test/pukllay_club_web/about_header_morph_test.exs)

## Accomplishments

- Closed UAT gap G-01.4-3 by addressing all three independently-necessary root causes the debug session identified: the mb-8 magnitude deficit (C1), the hero's inverted above/below allocation (C2), and the zero-clear-space isologo asset's implication for how large the CSS gap has to be (C3).
- Reconciled `--pk-about-mark-h` from 200px back to the approved 180px (sketch 045 variant A3), and decoupled the anchor's height from the mark's height via a new `--pk-about-mark-clear` (80px) custom property and a `calc()`, so a future resize of the mark can no longer silently consume the space around it.
- Rebalanced `#about-hero`'s padding from `py-12` (48px above / 32px below) to `pt-2 pb-12` (8px above / 80px+ below), matching the design source's own allocation.
- Replaced the mb-6..12 literal spacing-tier test with one that gates the new calc() mechanism, and added a ratio-based regression test (`clear >= 40% of mark height`) that would catch a future re-introduction of this exact defect (mark grows, clearance doesn't move).

## Files Created/Modified

- `assets/css/app.css` — `--pk-about-mark-h: 200px` → `180px`; added `--pk-about-mark-clear: 80px` with its derivation recorded in a comment; `.pk-about-mark-anchor`'s height changed from `var(--pk-about-mark-h)` to `calc(var(--pk-about-mark-h) + var(--pk-about-mark-clear))`.
- `lib/pukllay_club_web/live/about_live.ex` — `[data-morph-anchor]`'s `mb-8` → `mb-0` (with a markup comment explaining the `space-y-3` neutralization); `#about-hero`'s `py-12` → `pt-2 pb-12`.
- `test/pukllay_club_web/about_header_morph_test.exs` — rewrote the spacing-tier test (mb-6..12 literal → mb-0 + calc() mechanism gate); added a new ratio-derivation test describe block; updated one stale "200px" example in an assertion message to "180px".

## Decisions Made

- Reconciled the mark to the approved 180px rather than leaving it at the shipped 200px and scaling the clearance up further — the 200px was itself unintentional drift (01.4-05's deliberate anchor breathing room silently consumed by the mark's own sizing, then welded in by 01.4-06's single-source refactor), not a design decision worth preserving.
- Set the regression test's floor at 40% (not the design source's exact 43.6%) to leave room for a deliberate downward adjustment during human UAT without the gate becoming a straitjacket, while still sitting far above the 16% that shipped and the entire mb-6/mb-10/mb-12 ladder (13-27%).
- Kept the clearance in the anchor's `height` (a `calc()`), not in a `margin-bottom` on `.pk-about-mark-anchor` — an unlayered `.pk-*` rule declaring `margin-bottom` would beat any Tailwind margin utility on the same element, the cascade hazard this stylesheet's own top-of-file note already documents.
