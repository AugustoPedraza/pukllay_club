### Pillar 5: Spacing (4/4)

**Strengths:**
- `.pk-band` padding is uniform: `4.5rem 0` (72px vertical, zero horizontal) applied to every section
- `.pk-band-inner` max-width: `80rem` (matches shell's max-w-7xl), with `.pk-gutter` class providing horizontal padding
- `.pk-about-rail` gap: `14px` (measured, intentional for scroll spacing)
- Photo carousel slide width: `flex: 0 0 min(84vw, 720px)` — responsive, not fixed-pixel
- Contacto card uses consistent `gap: 1rem` (16px) between heading, intro, icons, map
- FAQ items spaced with `space-y-7` (28px gaps)
- Hero section uses `space-y-3` (12px gaps) between eyebrow, heading, tagline, button
- Mobile CTA bar padding: `0.75rem var(--pk-gutter)` — horizontal scales with gutter, vertical is consistent

**No Issues:**
- No arbitrary spacing values like `[17px]` or `[3.7rem]`
- No per-band overrides of `.pk-band-inner` width (shared 80rem declaration throughout)
- No conflicting margin/padding that would cause drift

**Evidence:**
- `assets/css/app.css` lines 2582-2589: Uniform `.pk-band` and `.pk-band-inner` declarations
- `assets/css/app.css` line 2625: Rail gap is literal `14px`, not a Tailwind token but measured for carousel flow

- Screenshot shows consistent breathing room across sections

**Score Justification:** 4/4 — spacing is disciplined, measured, and consistent.

### Pillar 6: Experience Design (3/4)

**Strengths:**
- Photo carousel has working autoplay (4.5s interval), pause-on-hover, pause-on-touch (6s idle resume), pause-on-blur (document.hasFocus() guard)
- Navigation dots have `aria-current="true"` on active, `aria-label="Foto N"` on all buttons, 44px touch target (min-h-11 min-w-11)
- Isologo scroll-morph mechanic has reduced-motion support (skips entrance delay/glow, keeps tracking)
- All external links carry `target="_blank" rel="noopener noreferrer"` (WhatsApp, Instagram, Maps)
- Maps iframe has `tabindex="-1" aria-hidden="true"` (inert overlay with click-through anchor)
- CTA button reused across hero, mobile bar, closing band (Layouts.sumate_cta/1) — single source, no label drift
- Hero anchor has `aria-hidden="true"` (decorative floating element)

**Issues:**
- **OPEN FINDING (from 01.4-04):** Mobile hero tagline "Volvé a jugar. Volvé a encontrarte." wraps to ONE line at 375px and 414px viewports, not the TWO centered lines sketch 046 specified. Plan text states: "the tagline renders on ONE line at both widths (347px measured width at 375px, 386px at 414px — both comfortably fit 'Volvé a jugar. Volvé a encontrarte.' on one line). This does not match sketch 046's explicit two-line ask. Not silently accepted or force-wrapped — flagged here per the plan's own instruction for developer review."
  - **User Impact:** Mobile visual rhythm of hero may feel different from design intent; single-line tagline reads smaller/lighter than two centered lines would.
  - **Fix:** Either (a) shorten the tagline to force natural two-line break (e.g., "Volvé a jugar. / Volvé a encontrarte." or "Volvé a jugar\nVolvé a encontrarte."), or (b) add a forced line break in HTML if the current single line is acceptable, or (c) lower the breakpoint below `sm` (640px) if the two-line layout is only desired on very small screens.

- **PENDING HUMAN VERIFICATION (from 01.4-07/12):** Maps thumbnail caption chip visual treatment (opaque, inset 0.5rem, positioned at top, no overlap with Google attribution). 01.4-07 noted "perceptual sufficiency of the opacity/inset chip, real device, both themes, 4 viewports... flagged for end-of-phase review." 01.4-12 human checkpoint approved the live map but deferred "three human-check items" to phase-level UAT, including "confirm the transform-driven morph actually reads as 'subtle, polished, professional.'"

**Evidence:**
- `lib/pukllay_club_web/live/about_live.ex` lines 371-376: Both tagline variants render correctly in markup
- `lib/pukllay_club_web/live/about_live.ex` lines 397-507: `.AboutCarousel` hook implements all pause/resume/blur logic
- `lib/pukllay_club_web/live/about_live.ex` line 495: `document.hasFocus()` guard present
- `lib/pukllay_club_web/about_live_test.exs` confirms five dots render with correct aria attributes
- 01.4-04-SUMMARY.md D4 entry explicitly flags the one-line finding as "measured and reported, not fixed"

**Score Justification:** 3/4 because (1) interactive patterns are solid and well-implemented, (2) accessibility attributes are comprehensive, but (3) the mobile tagline line-wrap mismatch is a real, documented deviation from sketch spec that impacts the intended two-line visual rhythm, and (4) pending human checks on motion quality/visual polish remain for phase UAT.
