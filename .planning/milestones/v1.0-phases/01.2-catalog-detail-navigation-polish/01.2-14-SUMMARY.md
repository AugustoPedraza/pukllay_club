# Phase 01.2 Plan 14: Always-Full Juegos Similares Shelf Summary

**`Catalog.similar_games/1`'s hard `weight_band` WHERE filter became a band-preference `ORDER BY` term (Postgres `array_position`, bound as one `^` array param), guaranteeing a full 12-card shelf for every game — including the 26 no-band games that previously got no shelf — while D-06's exact intra-band overlap order stays byte-identical and a new daisyUI badge + subtitle swap (sketch 031) announces widening without touching the shelf's chrome.**
