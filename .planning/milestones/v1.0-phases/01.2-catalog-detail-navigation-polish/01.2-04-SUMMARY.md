# Phase 01.2 Plan 04: Ficha Técnica Trim & Buy-Box Redesign Summary

**Ficha técnica now shows only the five fields that can actually carry data (with a
`ficha_tecnica?/1` section-level guard closing the empty-heading edge case), and the buy-box
became a bounded `bg-base-200` panel with `pk-card-poster`-ratio cover art, a `btn-lg` full-width
reserve CTA, a top-right `btn-sm` share control, and a CSP-safe cover-failure fallback — all as
template class-list changes with no CSS file touched.**

## Accomplishments
- Removed the two unconditionally-rendered, permanently-"No disponible" Ficha técnica rows
  (Ilustrador, Puesto en el ranking BGG) — neither field exists on the `Game` schema or in
  `BggClient`, so there was no partial-data case to preserve.
- Removed the Jugadores/Duración Ficha técnica rows and their sole call site, `playtime_text/1`
  (all five clauses) — `GamePreview.facts_row/1` near the title stays the single
  players/duration representation, per D-05 as UI-SPEC already resolved it.
- Added `ficha_tecnica?/1`, a private predicate reading `min_age`, `year_published`, `designers`,
  `publishers`, and `bgg_id`, and put `:if={ficha_tecnica?(@game)}` on both the section `<h2>`
  and the `<dl>` — closing the UI-SPEC zero-one-many backstop so a minimal-data game shows no
  bare heading over an empty grid.
- Switched the buy-box's cover `<img>` and no-cover placeholder from `aspect-video` (16:9,
  borrowed from the unrelated hover-preview surface) to `pk-card-poster` (the shared `1/1.05`
  ratio every card on the site already uses).
- Wrapped `.pk-poster-col`'s contents in `bg-base-200 rounded-box p-4 space-y-4 relative`, giving
  the buy-box a visible secondary-surface panel boundary.
- Promoted the reserve button to `btn-primary btn-lg w-full` on its own row (dropping `flex-1`),
  and moved the share control into an `absolute right-2 top-2 z-10` wrapper anchored to the
  panel corner, no longer a flex-row sibling of the primary CTA.
- Added `btn-sm` to `share_control/1`'s trigger class list (kept `min-h-11 min-w-11`) — since
  the component is shared verbatim by the buy-box and the mobile CTA bar, this one change lands
  both D-07's desktop weight fix and the mobile bar's prominence fix simultaneously, without
  touching the bar's `flex-1`, height, padding, or transition timing.
- Added `js-cover-fallback` to the buy-box `<img>` plus a hidden sibling placeholder (mirroring
  `GameCard`'s shape verbatim), so a `cover_url` that 404s degrades to the same brand placeholder
  via the existing app-wide capture-phase `error` listener — no inline `onerror` attribute, no
  new JS.
- Inverted the dead-spec-row test into a regression guard (Ilustrador/BGG-rank rows absent),
  rewrote the players/duration assertions to check the facts row (present) vs. the spec list
  (absent) separately, and added six new tests: minimal-data (no section), bgg_id-only (section
  renders), poster aspect class, panel classes, CTA size/width + structural share placement, and
  the cover-fallback markup shape.
