# Phase 01.2 Plan 13: Buy-box shadow panel + stacked mobile CTA bar Summary

**Fixed a real CSS cascade-layer bug (unlayered `.pk-poster-col` position rule silently defeating a layered Tailwind `relative` utility below 768px) and ported both sketch 027's Elevated Shadow buy-box panel and sketch 028's stacked mobile CTA bar, closing UAT gaps G-01.2-5 and G-01.2-6.**

## Performance

- **Duration:** ~35 min
- **Completed:** 2026-08-26
- **Tasks:** 3
- **Files modified:** 3

## Accomplishments

- `.pk-poster-col`'s base rule flips `position: static` → `relative`, giving the
  absolutely-positioned share wrapper a real containing block below the 768px detail
  breakpoint (the ≥768px sticky override already worked, by accident); the redundant
  Tailwind `relative` utility was removed from `show.ex`'s class list — one declaration, in
  the file that already owns the element's layout
- Added a standing cascade-layer hazard comment at the top of `app.css`, naming the concrete
  `.pk-poster-col`/share-wrapper instance and stating the rule to follow: when a `.pk-*` rule
  and a Tailwind utility both want one property on one element, delete the utility and keep
  the rule
- Swept every `.pk-*` rule with a `position` declaration (18 base selectors) against the
  markup for a competing Tailwind position utility; only `.pk-poster-col` had a real conflict
  (the bug just fixed) — see the full checked list below
- Ported sketch 027 variant B's Elevated Shadow treatment onto `.pk-poster-col` (page-colour
  fill, 1px `base-300` border, `0 4px 12px` shadow via this file's `color-mix`/
  `--pk-shadow-color` idiom), replacing the `bg-base-200`/`bg-base-100` fill pair independently
  measured elsewhere at 1.415:1/1.086:1 contrast
- Gave `share_control/1` a `variant` attr (`:panel`/`:bar`, both call sites explicit) and two
  real shapes: `.pk-share-trigger` (a bordered circle with a soft shadow, replacing the
  barely-visible `btn-outline btn-primary btn-sm` string) and `.pk-share-trigger--bar` (a
  full-width labelled outline pill with a visible "Compartir" label as its accessible name)
- Restructured the mobile CTA bar into a stacked layout: `.pk-cta-bar-inner` stacks the
  reserve button (now `w-full`, not `flex-1`) over the share pill, capped to `68.75rem` — the
  same literal `.pk-detail-masthead` uses — so the bar aligns under the content column past
  that width instead of stretching edge-to-edge
- Recomputed `body.pk-has-cta-bar`'s reserved padding (`9.25rem` → `12.5rem`, derived:
  148px + 44px new row + 8px gap = 200px), same transition/curve, same source-order
  relationship with `body.pk-cta-parked`
- `.DetailChrome`'s scroll state machine (hide-while-scrolling debounce, footer-park
  `getBoundingClientRect` check, `offsetParent` guard, both transition curves) is untouched —
  confirmed via `git diff` showing zero hunks inside its script block
