<objective>
Close the last two mechanical asks in the mobile detail-page rework: the missing boundary before the
recommendations shelf, and the duplicated share control in the fixed bottom bar.

Both are small and both have a consequence that is easy to miss. The masthead and the "Juegos
similares" shelf are plain siblings inside one vertical-rhythm wrapper with no border, no background
change and no boundary treatment between them, so on a phone the shelf reads as more of the same
page. And the bottom bar stacks a full-width labelled share pill beneath its Reservar button — a
second share entry point competing with the icon already sitting on the poster's own corner. The
consequence hiding behind that second one is that the bar's reserved body padding was raised by
exactly that row's height when the stacked layout shipped, so removing the row without lowering the
padding leaves a dead gap above the footer that nobody will connect back to this change.

Purpose: a reader on a phone should be able to tell where the page stops talking about this game and
starts recommending others, and should never be offered the same action twice in one screenful.
Output: one boundary, one control in the bar, and the dead styling and dead code behind the removed
control cleared out rather than left dangling.
</objective>
