# Phase 01.1 Plan 08: Header Rework — Search-Morph, Sumate CTA Relocation, Footer Theme Toggle Summary

**Reworked the shared header to sketch 017-E: a single 44px-icon-to-pill search-morph now serves both Catálogo and Detalle, the `Sumate` join CTA moved from every header to the About hero (D-05 superseded), the theme toggle became three bare monochrome icons in the footer, and `.CatalogNav` now publishes `--pk-header-h` for the header's real measured height.**

## Accomplishments

- `header_inner/1`'s `nav_search` slot is wrapped in `.pk-search-morph` — one element with a static `class` attribute and a `data-search-expanded` attr, converting from a 44px icon to a 17.5rem pill without ever swapping DOM nodes
- `.CatalogNav` (still the only colocated hook in `layouts.ex`) gained `publishHeaderHeight()` (`--pk-header-h` via `ResizeObserver` + an `updated()` callback) and the morph's open/close/Escape/click-outside behavior, guarded on `this.morph` existing
- `CatalogLive.Index` reads a bounded `?q=` URL param (`initial_q/1`, capped at 100 chars) and pre-expands the morph; `CatalogLive.Show` gained a `<:nav_search>` GET form back to the catalog root, making search reachable from the detail page for the first time
- D-05 superseded: `Layouts.sumate_cta/1` is now a public, About-hero-scoped component (outline-at-rest/fills-on-hover per sketch 013-E); the header carries no join CTA anywhere, replaced by tests asserting both absence (header) and presence (About hero, both `/club`/`/quienes-somos` aliases)
- `theme_toggle/1` rebuilt bare and relocated to `footer/1`'s right cluster behind a "Tema" tag; active state is now a CSS underline reading `<html>`'s existing `data-theme`/`data-theme-source` attributes, not a sliding pill
- Nav links flattened to 013-E's rest weight with 015-A's single active offset rule; `brand_logo/1`'s real nested `flex-1` double-grow bug fixed; Detalle's crumb gained base-width ellipsis truncation for the row band the shipped ≤480px collapse doesn't cover
