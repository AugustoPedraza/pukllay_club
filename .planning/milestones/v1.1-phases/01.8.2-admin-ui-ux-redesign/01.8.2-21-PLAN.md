## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff-pasted BGG id or URL -> Catalog + BggClient | untrusted external input reaches an outbound HTTP call and a unique-ish column |
| enrichment worker -> the open editor | a background write races a staff member's in-progress edit |
| Copias stepper -> copy rows | a count change creates or destroys physical-inventory records |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01.8.2-99 | Tampering | a save writing a stale placeholder name over the name BGG just supplied | high | mitigate | the editor subscribes to `{:game_enriched, id}` and refreshes the saved baseline only for untouched fields, asserted in both directions |
