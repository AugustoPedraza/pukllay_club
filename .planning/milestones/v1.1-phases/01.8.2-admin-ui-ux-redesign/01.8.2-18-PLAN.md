## Trust Boundaries

|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01.8.2-81 | Tampering | deleting an estante cascading its copy rows away, losing copy identity permanently | high | mitigate | `copies.shelf_id`'s `on_delete: :nilify_all` is verified rather than assumed, and a test asserts the copies still exist with a nil shelf after a delete |
| T-01.8.2-82 | Tampering | an undo that restores the estante but not the arrangement, silently losing the walk | high | mitigate | the delete returns a `{copy_id, position}` snapshot taken inside the same locked transaction, and a distinct restore function replays it whole rather than looping a single-copy restore |
| T-01.8.2-83 | Spoofing | a delete confirmed in a sheet row, reading as one more option | high | mitigate | D-19f's centred dialog, asserted by a test that the dialog is not nested inside a sheet |
| T-01.8.2-84 | Tampering | a duplicate estante name slipping through a check-then-insert race | medium | mitigate | the duplicate error is raised from the existing `unique_constraint(:name)` rather than a pre-check query, so the database decides |
| T-01.8.2-85 | Elevation of Privilege | the two new routes reachable without staff | high | mitigate | both are declared inside the existing `live_session :require_staff` block, and each has a signed-out-redirect test |
| T-01.8.2-86 | Denial of Service | a per-row copy-count query across every estante | low | mitigate | the counts are batched, pinned by an acceptance criterion |
</threat_model>
