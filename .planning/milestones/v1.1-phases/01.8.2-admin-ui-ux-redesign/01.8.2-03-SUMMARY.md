## Decisions Made

- **"agregado" split** (open item 5, #1): creation = `Borrador creado`, arrival = `Agregado al
  club` (e.g. `Catan: agregado al club`). `agregado` now means arrival only — every creation-path
  string in the copywriting contract uses `Borrador creado` or equivalent, never `agregado`.
- **`Editar`, not `Ver`** (open item 5, #2): the enrichment-completion toast's action. Toast =
  message `{Nombre}: agregado al club` + action `[ Editar ]`, using the decided arrival phrasing
  rather than the older "ya tiene sus datos" wording.
- **One-word `Guardar`** (open item 5, #3): confirms D-00a / sketch 065 R7 #3. 01.8.1's shipped
  `Guardar cambios` (line 144) is explicitly superseded, called out both in the new UI-SPEC's
  copywriting contract and in the supersession banner on `01.8.1-UI-SPEC.md`.
- **`+` sheet hint voseo fix**: rewrote "hasta que lo publiques" (tuteo-shaped, per its own sketch
  README) to the person-neutral infinitive "hasta publicarlo" rather than guessing at a
  voseo-conjugated subjunctive ("publiqués") — this project's existing voseo copy ("Vas a poder",
  "Probá", "Tenés") has no precedent for a conjugated subjunctive form, so the infinitive
  sidesteps the ambiguity entirely while still eliminating every tuteo form.
