as a reversible, counted migration against re-measured facts. Sketch 078 proved the drawn
publish gate is pure paint by publishing through the other door; this plan closes that door.

`restore_game(%Game{status: :retired} = game)` one clause below them does not —

`g.weight_band == ^band and g.status == :published` while the very next clause,
`section_query(%Section{kind: :recent, ...})`, already carries `g.is_expansion == false`.

`seed_changeset/2`, the retired CSV path. The weight-band bug is masked today only because
all 26 expansions have a NULL nivel — and D-30's new flow puts staff in front of that field.

Output: two guarded status transitions, one corrected section query, a validated
`enrichment_status` with a DB CHECK, and the D-36 unpublish migration.
</objective>
