# Plan 22 — The rollout

## Status: complete, with one requirement permanently unmet

Tasks 1 and 3 are done. **Task 2 was never executable**: the deploy it was
written to gate had already run by the time the plan reached it.

## The central finding

`.github/workflows/deploy.yml` triggers on `push` to `main`. **Merging PR #68
*was* the deploy.** Run `36003197484` fired at `2026-09-24T13:04:31Z`, ran
`bin/migrate` in the production container, and went healthy at `13:09` —
roughly four hours before this plan's checkpoint was presented.

So the clear-slate migration ran against production with:

- **no pre-deploy `pg_dump`** (Step 1's blocking gate — Conditions A and B both unmet)
- **no pre-deploy baseline counts** (Step 2 — permanently unobtainable)
- **no D-07 pre-check** (Step 3 — satisfied, but only verifiable after the fact)

This is an ordering defect in the runbook's design, not an operator slip. A
runbook whose gates precede a deploy that fires on merge can only work if the
merge is itself the gated step.

## What held anyway

**D-07 held.** Deploy SHA `b774eb4e5a354552bee11f3ecce4663fa9108cf9` carries the
migration (`20260923140000_clear_estantes_and_assignments.exs`) *and* all three
rebuild screens (`EstanteLive.Index`, `.Pendientes`, `.Administrar`, routed at
`/admin/estantes*`). Verified statically in the tree and against production —
all three routes answer `302 → /admin/ingresar`, not `404`. The failure D-07
existed to prevent (a cleared shelf map with no screen to rebuild it) **did not
occur.** This was luck, not the gate.

**All 10 production smoke checks pass** against `https://pukllay.club`.

**The public catalog reconciles exactly:**

| Source | Number |
|---|---|
| 01.8.1 recorded pre-deploy baseline | 435 |
| rows `unpublish_still_empty_games` selects by design (8 `bgg_missing` + 15 `no_bgg_id` base + 26 `no_bgg_id` expansions) | 49 |
| production `/sitemap.xml`, measured 2026-09-24 | **386** |

`435 − 49 = 386`. Three independently-derived numbers agree, so the catalog half
of this rollout **is** verified against a genuine pre-deploy baseline.

## What is NOT verified

**What the migration cleared in production is unmeasured and unrecoverable from
this repo.** The developer declined to recover the count from the last
pre-migration nightly dump (`2026-09-23T08:16:11Z`, ~29h stale), on the basis
that production held no real shelf work. **That is a recorded assumption, not a
measurement.** Residual risk: if production did hold shelf assignments from
01.8.1, staff face unpriced walk-the-shelf re-work and no one will know why.

**A trap worth recording.** Run `36003197484`'s log contains
`{"estantes_removed":0,"assignments_removed":0,"copies_unplaced":0}`. This is
**not production** — it is the `quality` job running against a CI Postgres
service container, and it reads `0/0/0` because that database is empty. It is
the only such line in all 4,389 log lines, and it is precisely the shape of
evidence that would make this plan's central claim look verified when it is not.
Production's real counts went to the container's own log on the GCP host.

**Rollback is degraded.** The runbook's Rollback section is written around
Step 1's dump, which does not exist. Recovery for the shelf map is the
2026-09-23 nightly in R2 or nothing.

## Deviations

1. **Task 2 not executed** — impossible by the time it was reached. Developer's
   decision, recorded verbatim: *"Since still this doesnt have real data for
   shelf, I think is ok just run it"*, then *"Not need do the dump. continue"*.
2. **Not re-dispatched to a fresh executor.** Task 1 had already committed
   (`0a2c47ac`) with no SUMMARY — the `safe_resume_gate` condition. A bare
   re-dispatch would have restarted at Task 1, the decimal-phase resume bug
   CLAUDE.md documents. Remaining tasks were run by hand per that recovery path.
3. **`--expect-baseline` against `01.8.1-prod-baseline.json` now fails**
   (`386 < 435`) and should. Its floor semantics assume a monotonically growing
   catalog; the deliberate unpublish breaks that. The floor was deliberately
   **not** lowered to make it pass.
