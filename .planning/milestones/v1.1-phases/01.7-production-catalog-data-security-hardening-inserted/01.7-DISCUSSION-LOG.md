## Initial data population method

| Option | Description | Selected |
|--------|-------------|----------|
| Dump/restore from dev | pg_dump the `games` table from local dev DB, restore into production over the SSH tunnel. Zero BGG/Gemini API cost, byte-identical to dev. | ✓ |

| Just mix catalog.seed alone | Only the base seed task — production would ship with English descriptions and without later enrichments (content regression vs. dev). | |

**User's choice:** Dump/restore from dev (recommended)
**Notes:** Confirmed dev and production share the same R2 bucket
(`https://pub-8f053d9e82db4d8eb43b5666a37546c4.r2.dev`), so no image re-upload is needed. Scope
narrowed to the `games` table only (not a full database dump) — smallest safe surface, no
migration/schema state crossing environments.
