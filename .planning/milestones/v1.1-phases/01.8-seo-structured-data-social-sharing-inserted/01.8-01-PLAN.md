<objective>
Land the CSP nonce refactor and the crawler-visible per-game SEO chain in one pass: a JS-free HTTP
GET of `/juegos/:id` must return that game's own meta description, Open Graph tags, Twitter Card
tags and `Game` JSON-LD, with the JSON-LD executing under a per-request nonce rather than a
weakened `script-src`.

Purpose: this is the phase's load-bearing slice. ROADMAP's build-order note is explicit that the
nonce must land first because JSON-LD cannot render at all under the existing strict
`script-src 'self'`; and PITFALLS Pitfall 1 is explicit that anything gated on the LiveView socket
is invisible to every crawler. Proving both ends in the first commit is what stops the rest of the
phase from being built on an architecture that never reaches a crawler.

Output: `CSP.policy/1`, a nonce-generating `put_csp/2`, the `PukllayClubWeb.SEO` payload builder,
the `GameSEO` and `SiteSEO` plugs, the `SEOTags` component, the `Catalog.OgCard` derivation module,
the rewritten pinned `script-src` regression assertion, and a new plug test directory.
</objective>

<assumption_delta_decision>
The `assumption-delta scan` fired a `pluralization` signal on the term "fallback" (ROADMAP success
criterion 1: "never the site-wide fallback"). The identity-model question it implies is whether the
existing single site-wide social-preview identity is being **promoted** to a per-game one, or
whether a per-game identity is being **added alongside** it.

**Decision: add-alongside, not promote.** The site-wide branded card (D-04) keeps its own distinct
identity and remains the correct answer for every hero-less route — catalog index, About. The
per-game card is a second, additional identity selected by route, resolved by `SiteSEO` assigning
the default and `GameSEO` overwriting it only on `/juegos/:id`. There is no migration of the
site-wide value into a per-game one and no "default game" concept. Consequence for the code: the
two payloads are built by two named functions on one module (`SEO.site_default/1`,
`SEO.for_game/2`), never by one function with a nil-game branch, so neither can silently degrade
into the other.
</assumption_delta_decision>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| crawler/browser → Phoenix router | Untrusted `:id` path param reaches `GameSEO` before any LiveView runs |
| `games` table → rendered `<head>` | Seeded game names and descriptions, originally sourced from BGG's XML API and a club CSV, flow into meta attributes and a JSON-LD script body |
| server → browser CSP engine | The nonce is the sole authority deciding which inline script the browser will execute |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01.8-01 | Tampering | `Router.put_csp/2` nonce generation | high | mitigate | Generate with `:crypto.strong_rand_bytes(24)` + `Base.encode64(padding: false)` once per HTTP request, in the same plug call that emits the header. Never `:rand`, never `System.unique_integer/0`, never cached or reused across requests. Task 1's test asserts two successive requests return two different values. |
| T-01.8-02 | Tampering / Elevation | `SEO.game_json_ld/1` → JSON-LD script body | high | mitigate | Build the payload as an Elixir map and encode with `Jason.encode!/1`; never string-interpolate JSON. Escape script-closing sequences in the encoded string before it reaches the template. Task 1's test drives a game name containing an angle bracket and a script-closing sequence and asserts exactly one script element survives. |
| T-01.8-03 | Tampering | `CSP.policy/1` refactor | high | mitigate | Append the nonce inside the existing `script-src` value via a derived `script_src/1` helper rather than adding a directive; leave the ten-directive count test and every other exact-equality directive assertion in `catalog_live_test.exs` untouched and passing, which is what catches accidental drift in `frame-src`, `base-uri`, `form-action` or `style-src` during the refactor. |
| T-01.8-04 | Information disclosure | `Plugs.GameSEO` game lookup | medium | mitigate | Call `PukllayClub.Catalog.get_game!/1`, whose documented parse-then-404 contract already converts both a nonexistent and a non-numeric id into `Ecto.NoResultsError` (a `Plug.Exception` rendering the branded 404). | T-01.8-05 | Spoofing | Open Graph image URL | low | accept | `og:image` resolves only to the app's own R2 image origin or the app's own static path; a game row cannot inject an arbitrary image host because the URL is derived from the stored cover URL's own path segment, not from a free-text field. No further control needed at ASVS L1. |
