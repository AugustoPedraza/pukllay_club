# Phase 01.8 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| crawler/browser → Phoenix router | Untrusted `:id` path param reaches `GameSEO` before any LiveView runs | request path param |
| `games` table → rendered `<head>` | Seeded game names/descriptions (originally sourced from BGG's XML API and a club CSV) flow into meta attributes and a JSON-LD script body | untrusted-provenance text |
| server → browser CSP engine | The per-request nonce is the sole authority deciding which inline script the browser executes | CSP nonce |
| `games` table → rendered HTML attribute | Game names/publisher strings flow into an `alt` / accessible-label attribute | untrusted-provenance text |
| crawler → `/sitemap.xml` | Unauthenticated, uncached public endpoint running a full-table query on every request | HTTP request |
| `games` table → XML document body | Row-derived values interpolated into a machine-parsed XML document | untrusted-provenance text |
| R2 public origin → libvips decoder | Stored cover bytes fetched over HTTP and decoded by a native image library | image bytes |
| developer machine → R2 bucket | The og-card backfill batch holds write credentials and writes ~400 objects in one run | R2 write credentials |
| `games.cover_url` → object key derivation | A stored database string determines which object key the batch writes to | derived storage key |
| compile-time club facts → public structured data | The club's real street address and phone number become permanently public, machine-readable data | PII (public-facing business contact) |
| `games`/club data → JSON-LD script body | A second inline script element (`LocalBusiness`) added to every page under the CSP | untrusted-provenance text + nonce |

## Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation | Status |
|-----------|----------|-----------|----------|-------------|------------|--------|
| T-01.8-01 | Spoofing | CSP nonce generation | high | mitigate | `:crypto.strong_rand_bytes(24)` + `Base.encode64`, generated once per request in `router.ex`'s `put_csp/2` | closed |
| T-01.8-02 | Tampering | Game JSON-LD payload | high | mitigate | `Jason.encode!/1` + script-closing escape (`/`→`\/`) before `SEO.json_ld_tag/2` | closed |
| T-01.8-03 | Elevation of Privilege | CSP `script-src` | high | mitigate | Exactly 10 directives preserved; nonce appended inside `script_src/1`, no new directive added | closed |
| T-01.8-04 | Information Disclosure | `GameSEO` plug game lookup | medium | mitigate | Uses `Catalog.get_game!/1` (public read path), never `Repo.get!/2` directly | closed |
| T-01.8-05 | Spoofing | `og:image` URL derivation | low | accept | `og:image` derived from the game's own stored cover path, never free text — accepted, no injection surface | closed |
| T-01.8-06 | Tampering | Accessible-name (`alt`) rendering | medium | mitigate | `GameText.cover_alt/1` returns a raw string; HEEx escapes at render time, never pre-escaped | closed |
| T-01.8-07 | Denial of Service | Publisher-list rendering | low | mitigate | Explicit `%Game{publishers: []} → nil` clause — empty array never reaches interpolation | closed |
| T-01.8-08 | Information Disclosure | Publisher/name duplication across attributes | low | accept | Name/publisher already visible elsewhere on the page — no new exposure | closed |
| T-01.8-09 | Tampering | Sitemap XML body | high | mitigate | `escape/1` applied to every interpolated `loc` value in `sitemap_controller.ex` | closed |
| T-01.8-10 | Denial of Service | Sitemap full-table query | medium | accept | 434-row indexed query — well within budget for this catalog size | closed |
| T-01.8-11 | Information Disclosure | Sitemap row visibility | medium | mitigate | No visibility/draft/soft-delete field exists on the `games` schema — nothing to leak | closed |
| T-01.8-12 | Tampering | `robots.txt` content | medium | mitigate | Real content ships; zero commented-out ban directives left uncommentable | closed |
| T-01.8-13 | Denial of Service | og-card cover fetch → libvips decoder | high | mitigate | Existing streaming 15MB cap + image content-type check reused unchanged in `image_pipeline.ex` | closed |
| T-01.8-14 | Spoofing | og-card fetch host allowlist | high | mitigate | Both `image_pipeline.ex` and `csp.ex` read the same `:pukllay_club, :image_origin` application key — allowlist and CSP can never diverge | closed |
| T-01.8-15 | Tampering | og-card object key derivation | medium | mitigate | `OgCard.object_key_for/1` is the exact inverse of `Credentials.r2_object_url/2`; returns `nil` on any mismatch rather than guessing | closed |
| T-01.8-16 | Information Disclosure | og-card backfill R2 credentials | medium | mitigate | `Credentials` struct constructed once by the Mix task and passed explicitly; the batch module never reads application env | closed |
| T-01.8-17 | Tampering | Immutable, non-overwritable og-card objects | medium | accept | `put/4`'s head-check-and-skip + one-year immutable cache mean a content change needs an explicit delete pass — accepted cost of the batch architecture | closed |
| T-01.8-18 | Information Disclosure | LocalBusiness address/phone publication | medium | accept | Address and phone are already the club's public-facing contact info (Instagram, WhatsApp group) — no new exposure | closed |
| T-01.8-19 | Elevation of Privilege | LocalBusiness JSON-LD nonce agreement | high | mitigate | Rendered via `SEO.json_ld_tag/2` under the same per-request nonce as the `Game` block — no hash-source, no `script-src` widening | closed |
| T-01.8-20 | Tampering | LocalBusiness JSON-LD payload | high | mitigate | `Jason.encode!/1` + the same script-closing escape helper plan 01 introduced | closed |
| T-01.8-21 | Spoofing | OG-fallback asset serving | low | accept | Served from the app's own origin via `Plug.Static`, already covered by the existing `img-src` CSP directive | closed |

*Status: open · closed · open — below `high` threshold (non-blocking)*
