# Phase 01.8 Plan 03: Live Sitemap & Real robots.txt Summary

**A request-time `GET /sitemap.xml` built fresh from `Catalog.sitemap_entries/0` on every call, plus real `robots.txt` content naming it absolutely — the two discovery primitives Google needs before any of this phase's other SEO work can be found.**

## Performance

- **Duration:** ~25 min
- **Completed:** 2026-09-12
- **Tasks:** 2 (Task 1: tdd, sitemap.xml; Task 2: auto, robots.txt)
- **Files modified:** 6 (3 created, 3 modified)

## Accomplishments
- `PukllayClub.Catalog.sitemap_entries/0` selects only `id`/`updated_at`, explicitly ordered by `id` — the single source of truth `SitemapController` reads on every request, never a build-time or cached snapshot.
- `PukllayClubWeb.SitemapController` mirrors `HealthController`'s shape (its own `:sitemap` router pipeline/scope, no session/CSRF/CSP) and builds the XML body by explicit string construction with every interpolated value escaped.
- `lastmod` is derived via two private function clauses (`%DateTime{}`/`%NaiveDateTime{}`) rather than betting on `games.updated_at`'s ambiguous bare-`timestamps()` struct type, sidestepping a possible `FunctionClauseError` on a public URL (RESEARCH.md Pitfall C).
- `priv/static/robots.txt` now carries real content — a wildcard `Allow: /` section and an absolute `Sitemap:` directive naming `https://pukllay.club/sitemap.xml` — with every comment line from the Phoenix default stub removed outright, not left in place.
- 14 new tests cover entry count vs. live catalog count, per-game `lastmod`, no fabricated `priority`/`changefreq`, duplicate-`updated_at` non-merging, the empty-catalog edge case, request-to-request byte-identical bodies, insert-between-requests visibility, and the full `robots.txt` content contract.

## Decisions Made
- `sitemap_entries/0`'s `@doc` records that `games` carries no visibility/soft-delete column today, so every row is selected — a future phase adding such a column must extend this query at the same time (T-01.8-11).
- `lastmod/1` pattern-matches both `%DateTime{}` and `%NaiveDateTime{}` rather than calling a single type-specific formatter, since RESEARCH.md's Pitfall C established that `games.updated_at`'s struct type cannot be determined from source alone.
- `robots.txt`'s test asserts the `Sitemap:` line's path portion against the router's own `~p"/sitemap.xml"` route (not a hardcoded string), so a future route rename fails the test loudly — the absolute host literal itself is a documented, unavoidable second literal (a static file served by `Plug.Static` cannot be templated against `Endpoint.url/0`).
