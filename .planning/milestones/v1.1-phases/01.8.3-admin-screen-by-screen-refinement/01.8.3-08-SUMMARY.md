## Accomplishments

- Closed `G-01.8.3-2c`: the pinned caption band and the row divider's right end now sit on the SAME horizontal axis as every list row, the caption ink, and the search field — 32px, viewport-relative, at 360/375/390, at rest and while really pinned. ## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `measureJuegosKeelAt` would have compared the wrong section's header against the measured rows**
- **Found during:** Task 1, while implementing the viewport-relative rewrite
- **Issue:** At page load, all three sections' `<h2 class="pk-admin-juegos-section-heading-wrap">` headers exist in the DOM (`section/1`'s header markup is unconditional), but only the always-expanded "Juegos del club" section's `.pk-admin-juegos-rows` div is rendered (Borradores/Retirados start collapsed, per `index.ex`'s default `collapsed_sections`). The band-vs-row comparison would then have been comparing two unrelated sections' geometry, not the plan's intended same-section comparison.
- **Fix:** Scoped the header lookup to the SAME section as the measured rows via `row.closest('.pk-admin-juegos-section').querySelector('.pk-admin-juegos-section-header')`, in both `measureJuegosKeelAt` (resting state) and the pinned-state extension of `measureJuegosSectionPinned` (which was already correctly scoped via its own `sectionSelector` parameter).
- **Files modified:** test/visual/admin_shell.mjs
- **Verification:** RED transcript's band/divider numbers (16/16, 84/16) match the diagnosis's own independently-measured numbers for "Juegos del club" exactly — confirming the scoping fix reads the intended section, not a coincidentally-similar wrong one.
- **Committed in:** `1fee82ff` (Task 1)
