## Refinement depth

Claude diagnosed both reported defects before asking, so the options were grounded:
- **Width:** all nine admin screens hand-copy `<div class="mx-auto w-full max-w-3xl space-y-6">` with no gutter, while the site header uses `max-w-7xl pk-gutter`. Inside that wrapper, captions and rows self-inset 16px but the two forms inset nothing. Recorded as determined (D-16) rather than asked, since adding container padding would double every child's inset to 32px.
- **Opacity:** the `[data-pinned="true"]` rule (`juegos.css:116`) and its IntersectionObserver (`admin_list.js:92-110`) both already exist — so G-01.8.2-4 is not a missing rule.
