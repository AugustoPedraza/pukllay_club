## Accomplishments

- Migration `create_shelves`: `shelves` (`name` unique, `position`) + nullable `games.shelf_id` (`on_delete: :nilify_all`) — deleting a shelf unplaces its games, never deletes them.

## Issues Encountered

Both routes are present and correctly wired (`grep -n "estantes" lib/pukllay_club_web/router.ex` shows both), confirmed by passing tests against each route — this is an imprecise grep pattern in the plan's own acceptance text, not an implementation gap.

Used a longer, distinctive shelf name (`"Estante-Test-Ludoteca"`) instead — the dedicated `shelf_privacy_test.exs` already uses the same discipline (`"Estante-Secreto-Test"`).
