# Phase 01.8.1 Plan 04: Retire the CSV Seed Path Summary

**Deleted `mix catalog.seed`, its CSV/import/classifier modules, and `Catalog.upsert_game!/1`'s clobbering replace-all upsert entirely (D-09), made `mix catalog.translate_descriptions`' still-English filter unconditional, added a guard test proving every surviving offline task leaves club-owned fields untouched, and rewrote AGENTS.md's catalog data runbook for a database-is-source-of-truth world.**

## Accomplishments

- Deleted `lib/mix/tasks/catalog.seed.ex`, `Catalog.Seed.CsvImport` (and its `NimbleCSV.define`), `Catalog.Seed.HashtagNormalizer`, `Catalog.Seed.ExpansionClassifier`, the club's `ludoteca.csv` export, its seed report, and their three dedicated tests — grepped the tree first to confirm each deleted module's only callers were the seed task or each other.
- Deleted `Catalog.upsert_game!/1` — the `on_conflict: {:replace_all_except, ...}` upsert that would have silently reverted any admin edit on the next full re-seed — and rewrote every doc paragraph in `catalog.ex` and `game.ex` that named it, the CSV seed, or `ExpansionClassifier` to describe the admin as the write path and `is_expansion` as a staff-editable, club-owned field (D-07).
- Removed the now-unused `nimble_csv` dependency from `mix.exs`/`mix.lock` (`mix deps.unlock --unused`), keeping `mix deps.unlock --check-unused` green.
- Made `mix catalog.translate_descriptions`' still-English filter unconditional: dropped the `--only-english` CLI flag and its doc paragraph, renamed the two-clause `maybe_filter_only_english/2` to `filter_still_english/1`, and exposed the full selection (`candidate_games/0` + source-text filter + still-English filter) as `@doc false def candidates/0` so it is directly testable without calling Gemini.
- Added `test/pukllay_club/catalog/seed/db_source_of_truth_test.exs` (DataCase): proves `mix catalog.seed` no longer exists as a Mix task, `Catalog.Seed.CsvImport` no longer loads, and `Catalog.upsert_game!/1` is no longer exported; proves `StatsEnricher.enrich_from_bgg/2` (stubbed BGG, reusing `stats_enricher_test.exs`'s `Req.Test.stub` setup) and `StatsEnricher.backfill_artists_from_payload/1` leave a staff-curated game's name/units/weight_band/is_expansion/tags/description byte-identical; proves `candidates/0` excludes a Spanish-described game and includes a still-English one, unconditionally.
- Rewrote AGENTS.md's "Production data seeding" section (both the one-time-restore and future-re-seed subsections) into `## Catalog data: la base es la fuente de verdad` — states the database is the sole source of truth, keeps a one-sentence pointer to `01.7-SEED-RESTORE.md` (with the `setval` check as the callout lesson), lists the five surviving offline tasks and their club-owned-field guarantee plus the same three tunnel constraints as before, documents that production now enriches staff-added games itself via an Oban worker (reversing 01.7 D-04 per 01.8.1 D-02), and the owner bootstrap command.
