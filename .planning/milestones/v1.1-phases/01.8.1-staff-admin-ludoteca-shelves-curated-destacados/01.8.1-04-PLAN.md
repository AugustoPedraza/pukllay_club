## Phase Goal

**As a** club staff member (the owner or one of up to 3 invited staff), **I want to** sign in and
manage the ludoteca, record where each physical game lives, curate the home page's sections, and fix
mis-banded games, **so that** Saturday operations run smoothly and the home page stays alive.

<objective>
Retire the CSV seed path entirely before admin editing ships, so the database is the single source
of truth (D-09).

Purpose: `Catalog.upsert_game!/1`'s `on_conflict: {:replace_all_except, ...}` would silently revert
every staff edit (name, band, shelf, section membership) the next time anyone ran the seed. Retiring
the path is what D-09 locked, and it has to precede plan 05's edit screens.

Reversibility: D-09 is recorded one-way in CONTEXT.md and user-accepted (the CSV stops being an
editing surface). D-09 left one sub-choice open — remove the seed path or leave it present but
disabled — so the checkpoint below settles that before any deletion; the clobbering upsert goes
either way.

Output: deleted seed task, CSV import, hashtag/expansion classifiers, club CSV and upsert; an
English-only-by-construction translation task; a guard test; the rewritten AGENTS.md runbook.
</objective>
