<objective>
Remove the visually dated native sort dropdown ("Nombre", "Duración: …", "Complejidad: …",
"Más recientes") from the catalog page. It adds no value — the catalog is carousel shelves plus a
filtered grid, not a list a member manually scans and re-orders — and it is the only consumer of
its own client event.

Purpose: reduce a stale control off the catalog's primary surface without disturbing the sort
machinery underneath it, which is still load-bearing for the "Recientemente añadidos" see-all
expansion and for URL-param deep links.

Output: the dropdown markup and its orphaned event-handler clause are gone; test coverage for the
non-default sort path is retargeted at the URL-param entry point; the `ux-patterns` skill's
component inventory stops claiming the control exists.
</objective>
