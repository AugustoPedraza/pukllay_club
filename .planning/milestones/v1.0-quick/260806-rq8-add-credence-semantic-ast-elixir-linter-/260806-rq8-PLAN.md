<objective>
Add `styler` (adobe/elixir-styler — a `mix format` plugin that auto-fixes non-idiomatic Elixir)
plus supply-chain and dependency-hygiene checks (`mix hex.audit`, `mix deps.audit` via the
`mix_audit` package, `mix deps.unlock --check-unused`) to this project's `mix quality` alias, and
document the new pipeline in CLAUDE.md, STACK.md, and AGENTS.md.

**Revision note (supersedes an earlier draft of this plan):** an earlier version of this plan
targeted `credence` (a niche semantic/AST linter, ~3 months old, ~9.7K downloads, single
maintainer, no project-wide CLI task — would have required a hand-rolled
`lib/mix/tasks/credence_check.ex` wrapper around `Credence.analyze/2`). After further research the
user chose **Styler** instead: same underlying goal (catch/fix non-idiomatic Elixir, guard against
AI-generated code drift), but battle-tested (3.6M downloads, ~3 years old, Adobe-maintained,
current stable 1.12.2 verified live against hex.pm) and installs as a standard `mix format`
plugin — no custom Mix task needed. This plan is a full rewrite of the credence-related content;
do not resurrect the `credence_check` task or the `credence`/`Credence.analyze` references from
the earlier draft.

**Important scoping note carried over from research:** unlike credence, Styler requires *no* new
`mix quality` alias step — it hooks into `mix format` / `mix format --check-formatted` (already
step 4 of the alias) via `.formatter.exs`'s `plugins` list. Wiring it is a one-line addition, not a
new pipeline stage. The alias therefore stays at 7 steps (not 8, as the credence draft would have
had), since no dedicated `styler_check`-style step exists or is needed.

**Critical caveat that must not be skipped:** Styler's own README carries a documented warning —
"Styler can change the behaviour of your program" — with a concrete example (`case`->`if`
rewrites can alter semantics when a `case` clause's expression isn't strictly `true`/`false`; `if`
silently completes where the equivalent `case` would raise). Its own guidance: "look over any
changes Styler writes before committing to main." This plan's verification task treats that review
as a required step, not optional polish.

Purpose: keep AI-generated Elixir code idiomatic over time (per the "Guarding Against AI Drift"
rationale that prompted this task) using a mature, battle-tested tool, and close a supply-chain/
dependency-hygiene gap that Credo/Sobelow don't cover.
Output: `mix quality` runs 7 gates end-to-end and passes, with Styler active as a format plugin;
CLAUDE.md/STACK.md/AGENTS.md document the new pipeline.
</objective>
